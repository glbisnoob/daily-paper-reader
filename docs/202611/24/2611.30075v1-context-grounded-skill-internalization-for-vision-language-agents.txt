## Abstract 

Skill internalization offers a way for agents to learn use-ful behaviors from skills and use them without explicit guid-ance in context at inference time. A common approach is to generate demonstration trajectories with the skill in con-text and then fine-tune the same model on its own trajec-tories with the skill removed. However, this leads to the problem that the model may learn to reference the removed skill, which we named as context misalignment ( CoMi ). In this work, we first analyze agent behaviors related to CoMi 

under this common pipeline. Across ALFWorld [33], Web-Shop [44], and ARC-AGI-1 [7], skill-removed fine-tuning consistently results in CoMi : 12.2–46.0% of test trajecto-ries reference the removed skill. To address this problem, we develop Context-Grounded Skill Internalization (CGSI). CGSI uses a sentence detector to identify unsupported ref-erences and then masks or rewrites the selected sentences before fine-tuning. Experimental results demonstrate the ef-fectiveness of CGSI and reveal two key findings. (i) Com-pared with directly fine-tuning with the skill removed, CGSI reduces CoMi at test time by 72.5–94.6% while preserv-ing task success. (ii) Compared with existing reinforce-ment learning-based skill-internalization baselines, CGSI achieves comparable performance with substantially less training time. CGSI also significantly reduces processing costs compared with large-scale trajectory auditing and cor-rection.

A common way to internalize a skill is to generate demonstration trajectories with the skill in context using the model itself, and then fine-tune the same model on them with the skill removed. Llama 2-Chat follows this recipe for safety. It generates responses under a safety preprompt and is fine-tuned on its own responses without the preprompt [36]. SELF-ALIGN fine-tunes LLaMA on its own principle-guided responses with the principles re-moved [35], and agent training applies the same recipe to 1arXiv:2611.30075v1 [cs.AI] 23 Nov 2026 retrieved hints and reflection skills [9, 18]. This recipe is a supervised fine-tuning (SFT) form of context distilla-tion [2, 34]. It changes the training input but keeps the super-vision target, so the model learns to reproduce what it wrote with the skill. However, a target written with the skill can depend on it. Demonstration trajectories can contain state-ments that reference the skill, and these statements remain training targets after the skill is removed. Figure 1 shows an example from ARC [7]. A skill-guided agent plans to execute and verify its inferred rule with a script, solve.py, and explains, “The solve.py file doesn’t exist. According to the task guidance, I need to create it.” The trajectory carries two things into training, a useful strategy and a reference to the skill that supplied it. Once the skill is removed from the SFT input, training rewards the model for referencing guidance it cannot see. We call this context misalignment 

(CoMi), in which an output references a source absent from its visible context. We conduct a comprehensive analysis of this problem. After skill removal, CoMi appears in 18.3–75.4% of suc-cessful teacher trajectories across ALFWorld [33], Web-Shop [44], and ARC-AGI-1 [7]. This behavior can be car-ried over to the trained models. After fine-tuning on these trajectories with the skill removed, the models exhibit CoMi in 12.2–46.0% of test trajectories. To solve this, we introduce Context-Grounded Skill In-ternalization (CGSI) . The core of CGSI is a sentence de-tector that identifies sentences containing unsupported refer-ences after skill removal. We then rewrite or mask the loss on these sentences before fine-tuning without the skill. We evaluate CGSI on ALFWorld [33], WebShop [44], and ARC-AGI-1 [7] with the vision-language models (VLMs) Qwen3.5-4B and Qwen3.5-9B [28]. Under full-parameter SFT, its masking version reduces CoMi by 72.5– 94.6% relative to direct fine-tuning while preserving task success. For example, with Qwen3.5-4B on WebShop, CoMi falls from 46.0% to 3.4% without loss of task suc-cess. CGSI also substantially reduces the cost of trajectory auditing and correction. On ARC, its rewriting version re-duces the API cost of processing 2,281 trajectories from about $1,378 to $165. With Qwen3.5-4B on ALFWorld, CGSI reaches 85.0% success in 1.25 training hours, com-pared with 81.0% for Skill0 [25] in 19.1 hours. Our contributions are: • To the best of our knowledge, we are the first to define and systematically study context misalignment (CoMi) in skill internalization. We show that CoMi is common in successful demonstration trajectories and can be car-ried into trained models .• To solve this, we propose CGSI to correct training su-pervision that loses context support after skill removal, using a sentence detector to select sentences for loss masking or rewriting before fine-tuning. • Experiments demonstrate the improvement. CGSI re-duces CoMi by 72.5–94.6% at a low cost while preserv-ing the task success of the fine-tuned model. 

## 2. Related Work 

Agent training. By interleaving reasoning with tool calls and environment feedback [45], agents complete multi-step tasks in simulated homes [33], online stores [44], software projects [41], and open-world games [39]. Be-yond prompting, these agents are improved by post-training, which learns from demonstrations, human preferences [27], or a teacher’s outputs [1, 13]. For agents, SFT on in-teraction trajectories improves performance on the trained tasks [4] , while reinforcement learning (RL) methods such as GRPO optimize the policy directly using task-outcome rewards [31]. 

Agent skills. Skills package reusable procedures, knowl-edge, and experience that an agent can draw on across tasks [39, 50]. Since such skills must be provided at test time, recent work attempts to move them into the model weights. SFT-based internalization generates tra-jectories with the guidance and fine-tunes on them with-out it [9, 18, 46]; the same idea underlies context distil-lation [2, 34–36] and, more broadly, learning with privi-leged information [5, 15, 24, 38]. Other approaches use RL or self-distillation. Skill0 progressively withdraws skills during RL [25]. DGO optimizes the policy using trajecto-ries collected with guidance from an experience bank [3]. Self-distillation methods give the teacher privileged context, such as skills [40] or reference solutions [51]. Recent work has also begun to address context-dependent traces in train-ing trajectories. Harness-Zero masks reviewer-perspective reasoning by keyword matching [46], and DGO rewrites experience-dependent trajectories [3]. Both treat these traces as a data-cleaning step within their own pipelines. We study CoMi as a distinct problem and measure it in both demonstration trajectories and trained models. 

Hallucination and faithfulness. Hallucination research asks whether generated statements are supported by the source or the available evidence [26, 29], as unsupported statements undermine the reliability of model outputs and the trust users place in them [17, 20]. Faithfulness research asks whether stated reasoning reflects how the model actu-ally reached its answer [19]; chain-of-thought can be un-faithful to the factors that drove an answer [22, 37], mis-leading users about why a model behaves as it does. An agent with CoMi references guidance absent from its visible context and misstates the basis for its actions. 3.4. Misalignment in successful demonstration tra-jectories 

Table 1 shows that successful demonstration trajectories fre-quently contain references that lose support after skill re-moval, from 18.3% on WebShop-9B to 75.4% on ARC-9B. Model size does not predict the rate: the 9B teacher pro-duces fewer such references than 4B on WebShop (18.3% versus 64.8%) but more on ALFWorld and ARC. A natural fix is to ask the teacher not to mention the skill. This makes the problem worse: on 1,000 ALFWorld tasks, removal-induced CoMi rises from 38.9% to 51.9%. Some outputs now reference the prohibition itself: “The system instruc-tions say not to mention the skill or its contents in think-ing.” This reference is supported during rollout but loses its source when the skill-related instructions are removed be-fore SFT; prompt-level prevention is analyzed in Supp. F. 

## 4. Context-Grounded Skill Internalization 

VLM auditing is expensive: on ARC, scanning a successful demonstration trajectory costs at least 1.13–1.14M tokens on average, and auditing the 2,281 ARC-9B training demon-stration trajectories with a VLM costs about $1,200 at list price. CGSI places the audit between skill-guided genera-tion and skill-free SFT and performs it with a detector us-ing two signals: how much a sentence depends on the skill, and what it says. The detector is developed once (Fig. 2(a), Steps 1–3) and then reused frozen in context-aligned SFT (Fig. 2(b)).

4.4. Masking selected supervision 

Masking stops training the model to produce the selected sentences: a target token is masked when it lies entirely in-side a selected sentence. Let ˆmk,t ∈ { 0, 1} be 1 if target token t of turn k is masked and 0 otherwise. CGSI (Mask) sets the token weights in Eq. (3) to wk,t = 1 − ˆmk,t :

LMask = L(θ; c−, 1 − ˆm). (9) Masking changes only which tokens are supervised: the nor-malizer T still counts all target tokens, so the remaining tokens keep their loss scale, and the selected text stays in the teacher-forced prefix, so later reasoning and actions are conditioned exactly as before. Removing the supervision entirely matters: a softer variant that only down-weights the selected sentences leaves more CoMi, as shown in Supp. D. 

4.5. Rewriting selected text 

CGSI (Rewrite) uses a VLM to rewrite each selected frag-ment so that it holds without the skill. We then train on the rewritten trajectories without the skill. Rewriting keeps supervision on the corrected text but needs VLM calls; Supp. C gives details. 

4.6. A generate–audit–correct–train framework 

These steps form a four-stage framework (Fig. 2(b)): afrozen sampling policy generates demonstration trajectories with the skill; the detector marks the sentences that lose support under the skill-free training context; the selected sentences are masked or rewritten; and the model is trained on the corrected demonstration trajectories without the skill. In contrast, the VLM Audit baselines VLM Audit (Rewrite) and VLM Audit (Mask) use a full VLM audit to select sen-tences for rewriting or loss masking, respectively. The full algorithm is in Supp. C. 

## 5. Experiments 

5.1. Setup 

Environments and data. ALFWorld [33] covers six types of household tasks, with 274 test tasks; in Web-Shop [44], the agent searches for and buys a product that matches a shopping instruction, with 500 test tasks; and ARC-AGI-1 [7] requires inferring a grid transformation from a few examples, with 400 evaluation tasks. We run ARC as a multimodal agent task in which the agent sees the grids as an image and can write and run code. The skills pro-vide household procedures, shopping strategies, and grid-transformation guidance, respectively. Each model gener-ates skill-guided demonstration trajectories on 1,920 train-ing tasks for ALFWorld and for WebShop and on 6,360 ARC tasks; for a given model and benchmark, all methods train on the same successful demonstration trajectories. De-tectors are developed on separate pools of 673–680 tasks per benchmark. Details are in Supp. H. 

Training and evaluation. We train with full-parameter SFT and rank-16 LoRA [16] for three epochs. Unless oth-erwise specified, all SFT methods use the same skill-guided demonstration trajectories and are evaluated without the skill. Base is the untrained model. SFT (skill kept) retains the skill in the training input, whereas SFT (skill dropped) removes it. CGSI (Mask) and CGSI (Rewrite) mask or rewrite the sentences selected by our detector; they are the two variants of CGSI. VLM Audit (Rewrite) and VLM Au-dit (Mask) rewrite or mask the sentences selected by a full VLM audit. We also compare with Skill0, Skill-SD, and OPSD on ALFWorld-4B (Tab. 4). Kimi-K2.7-Code per-forms auditing and rewriting. Each model is evaluated with one rollout per test task. Success rate ( SR ) is the percentage of test tasks com-pleted: a WebShop task counts as successful only if it re-ceives the full score of 100, and an ARC task only if every predicted grid matches exactly. For trained models, CoMi is the percentage of test trajectories with at least one unsup-ported reference, audited without the skill. Humans agree with 255 of 260 sampled audit positives. To check for misses in long trajectories, GPT-6.1 Sol independently re-audits 1,245 Kimi-negative test trajectories. Humans adju-dicate the disagreements and confirm five misses. Training settings and metric definitions are in Supp. E and A. 

Compute. All experiments in this paper run on NVIDIA H800 GPUs (8 per node), using about 5,832 H800 GPU-hours in total; external VLM calls use about 40.44B tokens in total, about $43,421 at official API prices.

CGSI reduces CoMi while preserving task success. Un-der full-parameter SFT, CGSI (Mask) achieves task suc-cess statistically indistinguishable from that of SFT (skill dropped) in all six settings, while reducing CoMi by 72.5– 94.6%, for example 3.4% instead of 46.0% on WebShop-4B. The highest remaining CoMi rate is 10.25% on ARC-9B, where detector recall is lowest. Masking the sentences se-lected by the full VLM audit yields a CoMi rate of 7.50% in this setting. On the 4B demonstration trajectories, CGSI (Mask) zeroes the loss on only 0.08–1.21% of target to-kens, yet substantially reduces CoMi at test time. Mask-ing randomly chosen reasoning sentences that cover a sim-ilar share of target tokens (1.07% on WebShop-4B) leaves CoMi at 49.4% . Therefore, the reduction in CoMi comes from targeting sentences containing CoMi, not from train-ing on fewer tokens. Rewriting also lowers CoMi, with suc-cess close to that of SFT (skill dropped). Supp. D and I give the random control and examples. 

CGSI achieves similar results at lower API cost. Under full-parameter SFT, CGSI (Mask) achieves comparable task success to VLM Audit (Mask), with no significant decrease in any setting . Neither method consistently yields lower CoMi. For rewriting, CGSI (Rewrite) also achieves task success close to VLM Audit (Rewrite), with similar CoMi in most settings. On ARC-9B, both reach 29.50% success, with 6.00% and 4.75% CoMi, respectively. Both CGSI vari-ants avoid the full VLM scan. After detector development, CGSI (Mask) makes no API calls, and CGSI (Rewrite) uses the VLM only for rewriting, reducing API token usage by 91.0–96.1% across the three 9B settings (Sec. 5.5).

5.5. Data-processing cost 

We use Qwen3.5-9B results as examples. Table 5 reports the API tokens per successful demonstration trajectory across the three benchmarks. The detector reduces the cost of locating CoMi by replacing a full VLM scan with local feature extraction and classification. CGSI (Rewrite) then uses the VLM only for the rewriting stage, whereas CGSI (Mask) also avoids rewriting. On ALFWorld and WebShop, CGSI (Rewrite) uses 94.6% and 96.1% fewer API tokens than VLM Audit (Rewrite), respectively. 5.7. Does subsequent RL remove CoMi? 

If task-reward RL removed CoMi by itself, correcting the SFT data would be unnecessary. We test this by running 60 skill-free GRPO updates [31] from the SFT (skill dropped), CGSI (Mask), CGSI (Rewrite), and VLM Audit (Rewrite) policies. GRPO improves success from every starting pol-icy, as shown by the training curves in Supp. E. However, Fig. 3 shows that CoMi does not decrease in the same way. For SFT (skill dropped), the CoMi rate after RL remains at 69–86% of its pre-RL rate, with final values of 8.4–35.2%. Models trained with corrected SFT supervision finish at 0.4– 5.2%, with small increases or decreases during RL. A task reward indicates success, not whether the referenced source exists, so CoMi after RL is largely set during SFT.

## 6. Discussion and Conclusion 

In this work, we study context misalignment (CoMi) in skill internalization. We show that CoMi is common in success-ful demonstration trajectories and can be carried into trained models. To address this problem, we propose CGSI, which uses a sentence detector to guide rewriting or loss masking. Our experiments show that CGSI can substantially reduce CoMi while preserving task success. These findings high-light the importance of aligning training supervision with the model’s visible context when internalizing skills. 8LLM Usage Statement 

We study Qwen3.5-4B and Qwen3.5-9B as the models un-derlying the agents described in the paper. Kimi-K2.7-Code is used for training-data annotation, paired context audit-ing, trajectory rewriting, coherence checks, and deployment CoMi evaluation. GPT-6.1 Sol independently re-audits neg-ative deployment trajectories. OpenAI Codex assists with manuscript drafting and code preparation.

## Limitations 

Computational cost limits us to one training run per config-uration, so we do not measure variation across independent training runs. Nevertheless, our main findings are consis-tent across three benchmarks and two model sizes. This consistency across different tasks and models helps mitigate concerns that the observed patterns are specific to a single configuration. Resource constraints also lead us to use the same model for training-data annotation and test-time auditing, which raises concerns about potential auditor bias. We address this concern through human annotation checks and an inde-pendent audit using another model. Humans confirm 255 of 260 sampled audit positives. For trajectories initially labeled negative, an independent model re-audits 1,245 test trajectories, and humans adjudicate the disagreements. These checks support the reliability of our audit; details are provided in Supp. B.

## B. Audit protocol and validation 

Judgment and consensus. The auditor sees the actual vis-ible context and the target output, and returns a binary de-cision, exact fragments, their claimed sources, and reasons. Two independent calls A and B are blind to one another. When their binary decisions agree, B supplies the complete judgment; otherwise a third independent call C resolves the disagreement. Technical failures are retried. 

Paired labels for the detector. We first audit a training output without the skill. For a positive output, we restore the skill and audit the same output again. If it is now neg-ative, the skill-free fragments are removal-induced. If it re-mains positive, we check each candidate fragment with the skill restored and retain those whose reference is supported there. Exact string matching maps accepted fragments to the original output; overlapping sentences receive positive labels. 

Deployment audit. The deployed agent’s rollouts are au-dited under their actual skill-free inputs, using the same pro-cedure. A trajectory is positive if at least one turn contains an unsupported reference. 

Human and cross-model checks. Agent trajectories are very long, so exhaustive human review is impractical; we check the Kimi labels by human review of sampled pos-itives and by an independent cross-model audit of nega-tives whose disagreements humans adjudicate. For posi-tives, we drew a stratified sample of Kimi-positive turns across benchmarks, model sizes, collection and test phases, and methods, and showed one flagged passage per turn with its visible context; for collection turns, the reviewer also confirmed that the passage is supported once the skill is re-stored. Humans agreed with 255 of 260 passages (98.1%), 120 of 120 from collection and 135 of 140 from test tra-jectories (Tab. S2). For misses, GPT-6.1 Sol independently 12 re-audited every turn of 1,245 Kimi-negative test trajecto-ries (21,419 turns) of full-parameter SFT (skill dropped) and CGSI (Mask) on ALFWorld-4B and WebShop-4B with the original audit prompts, and humans adjudicated each disagreement. Sol disagreed on only five trajectories, two from SFT (skill dropped) and three from CGSI (Mask), and humans confirmed all five as CoMi, 0.40% of the rescanned negatives. A miss can only make a reported CoMi rate lower than it is, and misses are rare for both methods: adding the confirmed ones changes WebShop-4B from 46.0% to 46.2% for SFT (skill dropped) and from 3.4% to 3.8% for CGSI (Mask), so they do not affect the comparison. Reported CoMi rates keep the original Kimi labels.

## C. General training framework 

Algorithm 1 gives the full procedure of CGSI. It selects sen-tences with the frozen detector, which is fit once and reused on new demonstration trajectories. The VLM Audit base-lines VLM Audit (Rewrite) and VLM Audit (Mask) replace detector-based selection with a VLM audit of every turn. 

Checked rewriting. For each selected fragment, a VLM proposes a replacement that holds under the skill-free con-text while preserving the surrounding text and actions. Afresh CoMi audit and a coherence check decide whether the edit is accepted; rejected edits are retried a bounded number of times. Accepted edits form ˜τ , and the prefixes of later turns are rebuilt from the edited text before SFT without the skill, so later turns condition on the edited text. CGSI (Rewrite) applies this procedure to detector-selected sentences; VLM Audit (Rewrite) first audits every training turn with a VLM. 

## D. Sentence detector and word matching 

Segmentation and alignment. Reasoning is extracted be-fore “</think>”, falling back to the text before “<action>”. Sentence boundaries follow punctuation (“.”, “!”, “?”) fol-lowed by whitespace and line breaks. Character offsets map sentences and audit fragments to the original output. Feature pooling uses tokens intersecting a sentence, while masking uses tokens entirely within a selected sentence. Ac-tion tokens, format tags, and end-of-turn markers remain supervised. 

Features and fitting. The same initial model generates demonstration trajectories, initializes SFT, and serves as the frozen backbone q for feature extraction. The scorer uses BF16 forward passes and FP32 log-softmax with the same target tokens in both contexts. The hidden represen-tation has 2,560 dimensions for 4B and 4,096 for 9B. We L2-normalize the pooled vector, concatenate the two gap features, and fit a StandardScaler and logistic regression on the fit split. The classifier uses balanced class weights, L-BFGS, and inverse regularization C = 0 .1. This value was selected on ALFWorld-4B from {10 −4, 10 −3, 10 −2, 10 −1}

by out-of-fold average precision with three task-grouped folds, then reused for the other detectors. 

Threshold selection. We select thresholds on the calibra-tion split to favor high precision while maintaining high recall. For ALFWorld and WebShop, the selected thresh-olds give both precision and recall around 80% or higher. For ARC, achieving both is difficult, so we prioritize recall while keeping precision at an acceptable level. Table S4 lists each detector’s decision-score threshold with its preci-sion and recall on the calibration split; Tab. 3 evaluates the frozen detectors on successful SFT demonstration trajecto-ries. 

Word matching. The baseline marks a sentence posi-tive if it contains any of the following words, using case-insensitive matching with word boundaries:

OPSD and Skill-SD. Both start from Base and sam-ple student trajectories without skills; a skill-conditioned teacher scores the same generated prefixes. OPSD [51] uses self-distillation without a task-reward objective, with coef-ficient 1.0. Skill-SD [40] combines task rewards with an importance-weighted, sampled-token reverse-KL loss: 

LSkill -SD = LGRPO + 0 .001 LSDL . (14) The teacher scores are stop-gradient targets; the importance ratio corrects for sampling from the rollout policy. The orig-inal method extracts skills from trajectories and updates a skill bank during training. To compare training methods with the same guidance, we instead use fixed precomputed skills throughout, with no dynamic skill extraction or bank updates. Both methods run 60 updates on the 960-task pool, with 16 tasks and eight samples per task, learning rate 10 −6,and training temperature 1.0. Task and interaction. WebShop [44] asks an agent to find and purchase a product that satisfies a shopping instruc-tion, including requirements such as product type, attributes, options, and price. Task and interaction. ARC-AGI-1 [7] requires inferring a grid transformation from example input–output pairs and applying it to one or more test inputs. We evaluate on all 400 public evaluation tasks. We adapt the benchmark to a Harbor container [12] with an OpenHands harness [41]. The example pairs and test inputs are rendered together in an image attached to the first message, replacing the text-only presentation of Harbor’s original ARC adapter; the text matrices remain available in the file system. Terminal and file-editing tools let the agent implement a candidate rule in Python, test it on the examples, and write its predictions to “answer.json”. A task succeeds only when all predicted test grids exactly match the expected outputs, which are kept outside the agent’s environment. Episodes allow at most 30 interaction steps. We follow the OpenHands interaction pat-tern and retain the full preceding history, including images, reasoning, tool calls, and observations. 

Training trajectories. We generate training tasks with RE-ARC [14], whose 400 generators correspond to the of-ficial ARC-AGI-1 training tasks. For each generator, we accept 80 verified input–output pairs and group consecutive sets of four into 20 tasks, each with three demonstration pairs and one test input whose output is held out for veri-fication. This gives 8,000 tasks: 6,360 for SFT trajectory collection, 680 for detector development, and 960 reserved. The development pool contains 408 fitting, 136 calibration, and 136 held-out tasks; skill authoring and validation use 30 and 60 fitting tasks. Successful skill-guided collection yields 1,256 trajectories with 21,331 turns for Qwen3.5-4B and 2,281 with 37,732 turns for Qwen3.5-9B. All methods within each model size share the same cohort. Collection uses a 65,536-token total context limit and at most 12,288 generated tokens per call. All 28 model–method conditions use the same 400 evaluation tasks.
