## 摘要
图形用户界面（GUI）智能体可与移动端、Web端和桌面端界面进行自动化交互。然而，其较大的内存占用和重复的模型调用阻碍了其在资源受限设备上的部署，因而需要无需完整重训练的训练后量化（PTQ）。量化可能降低GUI响应准确率，并破坏GUI目标选择所需的指令-视觉亲和性和局部空间关系。微小的坐标误差可能导致点击失败，而早期动作错误可能改变后续界面状态并干扰任务执行。仅凭局部重建误差无法直接评估这些响应和关系是否得以保持。我们提出GUI-Q，一种以4比特权重和16比特激活（W4A16）实现响应与关系保持为目标的PTQ框架。任务敏感粒度分配（TSGA）在缩放字节预算下，通过结合响应敏感性与测得的激活加权失真降低量，分配更细粒度的分组。关系保持对称性选择（RPSS）随后选择对称或非对称网格，以保持GUI中的指令-视觉亲和性和局部空间关系。在三个具备GUI能力的模型上，相较于评估中最强的4比特配置，GUI-Q将平均grounding TargetHit提升8.04至12.55个百分点，同时相对于bfloat16（BF16）将静态峰值图形处理器（GPU）内存降低49.9%至56.2%。采用打包4比特执行的固定输出重放可实现1.7至2.8倍的模型调用加速。代码将公开。

## Abstract
Graphical user interface (GUI) agents enable automated interactions with mobile, web, and desktop interfaces. However, their large memory footprint and repeated model calls hinder deployment on resource-constrained devices, motivating post-training quantization (PTQ) without full retraining. Quantization can degrade GUI response accuracy and distort the instruction-vision affinities and local spatial relations needed for GUI target selection. Small coordinate errors can cause missed clicks, while early action errors can alter subsequent interface states and disrupt task execution. Local reconstruction error alone does not directly assess whether these responses and relations are preserved. We propose GUI-Q, a PTQ framework that targets response and relation preservation with 4-bit weights and 16-bit activations (W4A16). Task-Sensitive Granularity Allocation (TSGA) allocates finer groups under a scale-byte budget by combining response sensitivity with the measured reduction in activation-weighted distortion. Relation-Preserving Symmetry Selection (RPSS) then selects symmetric or asymmetric grids to preserve instruction-vision affinities and local spatial relations in GUIs. Across three GUI-capable models, GUI-Q improves mean grounding TargetHit by 8.04 to 12.55 points over the strongest evaluated 4-bit configurations, while reducing static peak graphics processing unit (GPU) memory by 49.9% to 56.2% relative to bfloat16 (BF16). Fixed-output replay with packed 4-bit execution provides 1.7 to 2.8 times model-call speedups. The code will be released.

## 一、核心问题与研究动机

- **部署矛盾**：GUI 智能体（UI-TARS、OS-Atlas、InternVL3.5 等 7–8B 视觉语言模型）需反复调用模型完成截图理解与动作生成。FP32 权重约需 26–30 GiB 内存，BF16 下静态峰值 GPU 显存仍达 15.75–16.67 GiB，难以部署到手机等边缘设备。
- **PTQ 的必要性与风险**：训练后量化（PTQ）无需完整重训练即可压缩权重，但量化会降低 GUI 响应准确率，并扭曲目标选择所依赖的**指令–视觉亲和性**与**局部空间关系**。GUI 任务对误差极敏感：微小坐标偏差即导致点击落空，早期动作错误还会改变后续界面状态、破坏整条任务轨迹。
- **现有方法的不足**：
  - 基于重建误差/激活感知缩放（GPTQ、AWQ）或敏感度、端损失、模态/Token 敏感度（VLM-PTQ、MBQ、QIG、GuidedQuant、QVLA、ActQuant 等）的方法，能定位"敏感模块"，却不能说明**何处采用更细分组收益最大**；
  - 序列平均目标无法显式区分数值型内容（坐标、动作参数）与其余响应；
  - 局部重建误差不直接度量指令–目标关联与空间关系是否保持。
- **整体含义**：论文主张 GUI 量化应同时满足两个目标——**响应保持**（在有限 scale 字节预算下保住输出）与**关系保持**（保住指令–视觉亲和性与局部空间关系），并据此设计粒度（group size）与对称性（sym/asym）两个决策轴。

### 2.1 总体框架

- 采用 **W4A16**：decoder 的 q/k/v/o 与 gate/up/down 投影量化为 4-bit 权重，激活与未量化组件保持 BF16。
- 每个模块配置 \(c_l=(4, g_l, a_l)\)，\(g_l\in\{64,128\}\)，\(a_l\in\{\text{sym},\text{asym}\}\)；G128 与 G64 的 scale 开销分别为 0.125 与 0.25 bit/权重（每 scale 存 2 字节），构成可度量的元数据权衡。

### 2.2 任务敏感粒度分配（TSGA）

- **响应分区**：将响应 token 分为 `seq`（全部）、`num`（解码后含 Unicode 十进制数字的 token，实测仅占 17.15–20.85%）、`non`（其余）；空掩码回退到全序列。固定权重 \((p_{seq},p_{num},p_{non})=(0.30,0.50,0.20)\)，在测试前确定，对所有模型统一。
- **敏感度代理**：对每类损失 \(L_{n,t}\) 求梯度 \(U_{l,t,n}=\partial L_{n,t}/\partial Y_{l,n}\)，用因子化近似
  \(\hat E_{l,t}=\frac1N\sum_n \text{mean}(H_{l,n}^{\odot2})\cdot\text{mean}(U_{l,t,n}^{\odot2})\)，
  仅保留响应行，属"响应受限的因子化排序代理"；经百分位归一化后加权得 \(R_l\)，并取 \(S_l^+=R_l+10^{-4}\)。
- **失真度量**：\(D_{l,g}\) 为激活加权相对重建误差（以 \(\|H W^\top\|_F^2\) 归一化），目标 \(J_l(g)=S_l^+\,D_{l,g}\)。
