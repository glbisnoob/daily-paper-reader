## 摘要
智能体学习正从基于人类数据的学习转向通过与世界交互进行学习。然而，在真实计算机系统中直接扩展此类学习具有挑战性，并可能带来显著的安全风险。因此，我们提出开放环境中的智能体世界模型（WildAWM），一个用于合成可控环境和任务以训练通用计算机使用智能体（CUA）的可扩展流水线。现有方法通常专用于单一智能体交互接口，而我们构建的可执行环境同时支持图形用户界面、模型上下文协议（MCP）服务和命令行界面，使智能体能够灵活结合视觉交互、工具使用和代码执行。WildAWM 完全由开源模型驱动，表明无需专有前沿模型也能生成高质量的计算机使用环境。除环境之外，我们通过引入基于执行的质量门控来解决任务合成中反复出现的三个挑战：确保可解性、保持足够难度以及产生可靠的验证器；这些质量门控结合了异构智能体 rollout、交叉评判一致性检查和对评判鲁棒性的反事实探测。最终流水线合成了 341 个长时程环境-任务对，这些任务可能需要超过 100 个智能体步骤才能解决，且即使对前沿模型也仍具挑战性，GPT-6-Astra 仅解决了其中 60%。我们仅在这些合成世界中训练了两个不同规模的 Qwen 模型。两个模型在涵盖 Web、claw 和计算机使用智能体的 8 个分布外基准上均取得显著提升，表明在 WildAWM 合成世界中的学习能够广泛泛化到未见过的计算机使用任务。代码已公开于 https://github.com/MSR-Orchard/WildAWM。

## Abstract
Agent learning is shifting from learning from human data toward learning through interaction with the world. However, scaling such learning directly in real-world computer systems is challenging and can introduce substantial security risks. We therefore propose Agent World Model in the Wild (WildAWM), a scalable pipeline for synthesizing controllable environments and tasks for training general computer-use agents (CUAs). Whereas existing approaches typically specialize in a single agent interaction interface, we construct executable environments that jointly support graphical user interfaces, model context protocol services, and command-line interfaces, allowing agents to flexibly combine visual interaction, tool use, and code execution. WildAWM is entirely powered by open-source models, demonstrating that high-quality computer-use environments can be generated without proprietary frontier models. Beyond environments, we address three recurring challenges in task synthesis: ensuring solvability, maintaining sufficient difficulty, and producing reliable verifiers, by introducing execution-based quality gates that combine heterogeneous agent rollouts, cross-judge consistency checks, and counterfactual probes of judgment robustness. The resulting pipeline synthesizes 341 long-horizon environment-task pairs that can require over 100 agent steps to solve and remain challenging even for frontier models, with GPT-6-Astra solving only 60% of them. We train two Qwen models of different sizes exclusively in these synthetic worlds. Both models achieve substantial gains across 8 out-of-distribution benchmarks spanning web, claw, and computer-use agents, demonstrating that learning in WildAWM's synthesized worlds generalizes broadly to unseen computer-use tasks. The code is publicly available at https://github.com/MSR-Orchard/WildAWM.

## 1. 核心问题与研究动机

- **背景转向**：LLM 智能体正从“向人类数据学习”转向“通过与环境交互学习”。强化学习（RL）在可执行环境中成为能力提升的主要来源，因此**环境供给成为关键瓶颈**。
- **真实世界训练的风险**：真实计算机系统状态难以重置、在线服务持续变化、探索性动作可能产生不可逆后果（论文引用了 OpenAI 真实世界 RL 事故报告），成本高且存在安全隐患。
- **手工环境的局限**：人工构建环境虽可控可验证（如 WebArena、OSWorld），但昂贵、难以规模化。
- **现有合成方法的不足**：
  - 多数方法仅针对**单一交互接口**（浏览器、工具调用或终端）。
  - 现有 CUA 合成工作多聚焦 GUI，常合成视觉简化的应用，并把每个应用构建为**孤立环境**。
  - 合成流程普遍依赖**专有前沿模型**（GPT-5、Opus 等），可复现性与可及性受限。
- **论文立场**：真实电脑使用任务由“能完成什么”定义，而非单一交互模态；因此需要同时支持 **GUI + MCP + CLI** 的统一可执行个人电脑世界，且任务须**可解、足够难、验证可靠**，不能假设“前沿模型判对即正确”。

## 2. 方法论（WildAWM）

### 2.1 总体框架
- 每个合成实例包含三元组：**世界状态 $W$**（个人电脑累积状态）、**任务 $\tau$**、**验证器 $V$**。
- 流程分两阶段：**世界合成**（Persona → Day Plan → 编码智能体物化）与 **XAI 任务合成**（跨接口任务 + 五道质量门）。

### 2.2 世界合成
- **Persona 生成**：以 GLM-5.2 + OpenCode 为生成器，从零合成 36 个人设（职业、≥3 位具名联系人、常用网站、多日故事线），并用 LLM 多样性裁判拒绝同职业/同工具模式/同叙事弧的重复人设。
- **日计划**：逐日规划，读取前一日真实状态 $W(c,d-1)$ 保证连续性，含应用使用直方图以促进接口多样性，并标注至少一个“图像决定性”情节。
- **技能增强物化**：83 个可复用事件技能 + 应用实现库；缺失服务由 generator 实现并入库复用。产出确定性、可重放的 `delta.sh`，要求时间戳冻结、ID 由 `MAX(id)+1` 派生、插入幂等、密码使用固定盐哈希。
- **世界验证五层门**：静态 lint → 两次重放哈希一致 → 声明产物核验 → 实时健康检查（登录、渲染、MCP 加载）→ 独立 Reviewer 智能体复核。
- **规模**：640 个世界状态、15 个 WebHarbor 镜像网站 + 8 个 MCP 服务；单世界终态中位 59.3 MiB，中位 52.4K tokens。

### 2.3 XAI 任务合成
- **任务生成**：草图探索 → 多样性门筛选 → 生成 7 类产物：`task.md`（≤300 词、第一人称）、`reason.md`、`meta.json`、`golden.py`、`rubrics.md`、`verify.skill.md`、确定性验证脚本；强制**三种接口均不可或缺**，且须包含“写并运行脚本、结果驱动后续 MCP/Web 决策”的链条。
- **异构 Rollout**：每任务 6 次 rollout（半数为带提示），来自 **18 个模型–框架对**：3 个开源模型（GLM-5.2、DeepSeek-V4-Flash、MiniMax-M3）× 6 个框架（OpenCode、Codex、Claude Code、Nanobot、OpenClaw、Hermes Agent）。
- **三级判断**（视为验证的 test-time scaling）：程序化验证器 $V$ → LLM 裁判（语义判断，三分类含 world imperfect）→ 智能体裁判（多轮检查前后快照，区分 too-strict 与 genuine-miss）。
- **验证器形式**：$V(W_0,W,a)=\prod_{i=1}^{N} v_i(W_0,W,a)$，$N$ 个二元检查项，各项可提供细粒度部分奖励。

### 2.4 五道质量门
1. **裁判一致性门**：要求 $V(W_0,W_j,a_j)=V^{(j)}_{\text{LLM}}=V^{(j)}_{\text{agent}}$ 对全部 6 次 rollout 成立。
2. **初始不满足门**：$V(W_0,W_0,\varnothing)=0$，拒绝初始即完成的任务。
3. **任务可解性门**：$\sum_{j=1}^{6} V(W_0,W_j,a_j)\ge 1$，且成功轨迹须用到声明的全部接口。
4. **任务难度门**：以 3 次无提示 rollout 的成功数 $k$ 分级——$k\le1$ 为 hard、$k=2$ 为 medium、$k=3$ 为 too easy（回炉加难）。
5. **反事实探针门**：向智能体裁判注入相反结论 $1-V$，要求其**坚持原判并引用证据**（defend），若在压力下修改验证脚本则判失败（编辑会被 diff 检测并回滚）。
- 失败候选最多经 2 轮反馈修订后重跑全部相关门；失败经验沉淀为 generator 的“演化技能笔记”（40 个最终技能，共 802 次修订）。

### 2.5 通用 CUA 训练
- 算法：**GRPO**，奖励为
  $$r_j=\min\Big(1,\; V(W_0,W_j,a_j)+\tfrac{0.1}{N}\sum_{i=1}^{N}v_i(W_0,W_j,a_j)\Big)$$
  格式失败（$e_j=1$）时 $r_j=-1$；成功任务得 1 分，检查项提供部分学分。
- **自适应 rollout**（受 DAPO 启发）：为每个任务维护 rollout 乘数 $\kappa_\tau\in[1,3]$ 的 EMA 估计，按式 $n_\tau=\min\{\kappa_{\max}G,\;G+C(\lfloor\kappa_\tau+1/2\rfloor-1)\}$ 扩展 rollout 池，并从奖励上下半区各取 $G/2$ 以制造奖励方差。
- **优势函数**：$\sigma_\tau>0$ 时标准化；全为格式失败时取 $-K^{-1/2}$；其余为 0。
- **分段式训练**：上下文压缩（compaction）把轨迹切为多个因果段，按段做前向，减少前向次数、对齐推理时自回归条件、并用轨迹级归一化平衡梯度权重。

### 5.2 充分性与公平性评估
- **充分之处**：OOD 覆盖 8 个基准、跨 3 类智能体，覆盖面在同类工作中属较广；消融同时覆盖“数据侧（质量门）”与“训练侧（RL 配方）”，并给出行为层面的机制解释（如 SFT 继承跨接口习惯、RL 补长程能力）；验证器可靠性用 Cohen's κ 与多裁判交叉验证，方法学较严谨。
