## 摘要
图形用户界面（GUI）智能体将用户指令和屏幕截图转化为可执行动作。为学习可执行动作，现有方法在训练中通常依赖显式推理，这会促使模型过度依赖特定推理模式，而非可泛化的动作相关信息。本文提出一种隐式框架 RISE，将动作相关推理整合到隐式状态表示中以指导 GUI 动作预测。为此，通过三个互补的监督目标来捕捉动作相关推理：全思维链（full-CoT）状态对齐保留推理过程中的信息，动作分布对齐编码动作偏好，推理到动作边界对齐捕捉动作生成前一刻的表示。由此，RISE 能有效学习信息丰富的隐式表示，从而提高下一动作 token 预测的准确性。RISE 在 OSWorld-G 上达到 70.6% 的准确率，在比较的 8B 模型中取得最先进性能，较其骨干模型提升 4.3 个百分点。在两个不同骨干模型和六个多样化基准上的结果进一步证明了其在 GUI grounding 和动作预测中的有效性。我们的代码已在项目主页公开。

## Abstract
Graphical user interface (GUI) agents translate user instructions and screenshots into executable actions. To learn executable actions, existing approaches often rely on explicit reasoning during training, which encourage over-reliance on specific reasoning patterns rather than generalizable action-relevant information. In this paper, we propose an implicit framework, RISE, which integrates action-relevant reasoning into implicit state representations to guide GUI action prediction. To this end, action-relevant reasoning is captured through three complementary supervision objectives: full-CoT state alignment preserves information across the reasoning process, action-distribution alignment encodes action preferences, and reasoning-to-action boundary alignment captures the representation immediately before action generation. In this case, our RISE effectively learns informative implicit representations, thereby improving the accuracy of next-action token prediction. RISE achieves 70.6\% accuracy on OSWorld-G, establishing state-of-the-art performance among compared 8B models with a 4.3-point gain over its backbone. Results across two distinct backbones and six diverse benchmarks further demonstrate its effectiveness in GUI grounding and action prediction. Our code is available on our project page.

## 1. 核心问题与整体含义

- **研究背景**：GUI 智能体需要根据屏幕截图和用户指令预测可执行动作，包括操作类型、目标坐标和文本输入等。现有方法多采用自回归视觉语言模型，将推理过程、操作类型、坐标和输入文本统一序列化为 token 生成。
- **核心问题**：显式推理（explicit CoT）虽能提升动作预测，但存在两个关键缺陷：
  - **推理多样性**：同一动作可由不同推理路径表达，模型容易过拟合特定文本推理模式，而非学习可泛化的动作相关信息。
  - **推理—动作耦合弱**：token 级监督不强制推理语义与最终动作一致，可能出现“推理说保存、动作却点击取消”的不一致。
- **整体含义**：论文提出 RISE，用**输入相关的隐式状态表示**承载动作相关推理信息，在不生成中间推理文本的情况下指导 GUI 动作预测，从而兼顾泛化性、准确性和推理效率。

## 2. 方法论

### 2.1 核心思想

- 将截图、指令及交互历史构成多模态前缀 \(P\)。
- 在 \(P\) 后拼接 \(K\) 个可学习嵌入 \(Z\)，经因果 VLM 主干编码后取对应隐藏状态，得到隐式状态 \(R\)。
- 动作仍以自回归方式生成，但条件不仅包括原始前缀 \(P\)，还包括隐式状态 \(R\)；推理阶段**不生成任何中间推理文本**。
- 使用冻结的预训练 VLM 作为教师，提供三类互补监督，将教师显式 CoT 中的动作相关信息蒸馏到学生隐状态中。

### 2.2 关键技术细节

- **隐状态构造**：
  - 默认 \(K=8\)。
  - \(R = F_\theta([P;Z])_{n+1:n+K}\)，其中 \(F_\theta\) 为 VLM 主干。
  - 动作策略分解为  
    \[
    \pi_\theta(s|P,Z)=\prod_{j=1}^{L}\pi_\theta(s_j|P,Z,s_{<j})
    \]
  - 每个动作 token 可通过因果注意力同时访问原始多模态前缀和隐式状态。

- **三类动作相关推理对齐监督**：
  1. **全 CoT 状态对齐**：
     - 教师输入为 \([P;q]\)，其中 \(q\) 为标注 CoT。
     - 将教师 CoT 隐藏状态池化为 \(K\) 个有序目标表示 \(T\)，排除推理分隔符和动作 token。
     - 若教师 CoT 隐藏状态数 \(M\ge K\)，按连续分段平均；若 \(M<K\)，均匀采样并取整到 token 位置，必要时复用状态。
     - 损失为余弦相似度加 SmoothL1：
       \[
       L_{\text{state}}=\frac{1}{K}\sum_{i=1}^{K}(1-\cos(R_i,T_i))+0.1H(R,T)
       \]
  2. **动作分布对齐**：
     - 教师和学生使用相同 ground-truth 动作前缀进行 teacher-forcing。
     - 对动作 token 位置 logits 做温度 \(\tau=2\) 的软化：
       \[
       p_{T,j}=\text{softmax}(\ell_{T,j}/\tau),\quad
       p_{S,j}=\text{softmax}(\ell_{S,j}/\tau)
       \]
     - 最小化教师到学生的 KL 散度：
       \[
       L_{\text{KL}}=\tau^2\frac{\sum_j w_j KL(p_{T,j}\|p_{S,j})}{\sum_j w_j}
       \]
     - 权重 \(w_j\)：动作类型值 token 为 2，坐标值 token 为 4，其他为 1，强调坐标定位的重要性。
  3. **推理到动作边界对齐**：
     - 对齐教师处理完 CoT 后、预测第一个动作 token 前的隐藏状态 \(b_T\)，与学生处理完前缀和隐式状态后的边界状态 \(b_S\)。
     - 损失：
       \[
       L_{\text{bd}}=1-\cos(b_S,b_T)+0.1H(b_S,b_T)
       \]

- **训练目标**：
  - 加权动作交叉熵 \(C_w\)，权重与上述动作分布对齐一致。
  - 总损失：
    \[
    L=C_w+\lambda_{\text{state}}L_{\text{state}}+\lambda_{\text{KL}}L_{\text{KL}}+\lambda_{\text{bd}}L_{\text{bd}}
    \]
  - 权重分别为 \(\lambda_{\text{state}}=0.1\)、\(\lambda_{\text{KL}}=0.5\)、\(\lambda_{\text{bd}}=0.25\)。
  - 教师目标 detach，学生训练时输入不含 CoT，仅使用 \([P;Z;s^*_{<j}]\)。
