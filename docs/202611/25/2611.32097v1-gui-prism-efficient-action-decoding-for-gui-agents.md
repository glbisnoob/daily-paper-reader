## 摘要
图形用户界面（GUI）智能体将屏幕截图和用户指令转化为可执行动作。现有方法大多依赖视觉语言模型以文本形式生成动作，常因自回归解码而导致显著的推理延迟。为解决这一低效问题，我们提出GUI-PRISM，一种混合动作解码器，可直接预测动作类型和结构化参数，同时保留语言生成以处理开放式文本。与主要关注目标定位的现有空间解码方法不同，GUI-PRISM将直接预测扩展到动作类型及其相关参数，从而实现完整的GUI动作预测。具体而言，GUI-PRISM采用字段特定查询从共享多模态特征库中提取与动作相关的语义和空间信息，并进一步通过条件查询建模动作组件之间的依赖关系。门控残差交叉注意力利用细粒度多模态信息对这些预测进行细化。GUI-PRISM在ScreenSpot-v2上达到95.1%的准确率，比最强的基于预测头的空间解码方法高2.0个百分点，同时相比基线实现3.8倍推理加速。在AndroidControl-v2和MM-Mind2Web-v2上，其完整动作准确率分别提升4.8和0.7个百分点，同时相比基线分别实现2.7倍和3.9倍推理加速。我们的代码已在项目主页公开。

## Abstract
Graphical user interface (GUI) agents translate screenshots and user instructions into executable actions. Most existing approaches rely on vision-language models to generate actions as text, often leading to substantial inference latency due to autoregressive decoding. To address this inefficiency, we propose GUI-PRISM, a hybrid action decoder that directly predicts action types and structured arguments while retaining language generation for open-ended text. Unlike existing spatial decoding methods that primarily focus on target localization, GUI-PRISM extends direct prediction to action types and their associated arguments, enabling complete GUI action prediction. Specifically, GUI-PRISM employs field-specific queries to extract action-relevant semantic and spatial information from a shared multimodal feature bank. It further models dependencies among action components through conditional queries. Gated residual cross-attention refines these predictions using fine-grained multimodal information. GUI-PRISM achieves 95.1\% accuracy on ScreenSpot-v2, outperforming the strongest head-based spatial decoding method by 2.0 percentage points while delivering a 3.8$\times$ inference speedup over the baseline. On AndroidControl-v2 and MM-Mind2Web-v2, it improves complete-action accuracy by 4.8 and 0.7 percentage points while achieving 2.7$\times$ and 3.9$\times$ inference speedups over the baseline, respectively. Our code is available on our project page.
