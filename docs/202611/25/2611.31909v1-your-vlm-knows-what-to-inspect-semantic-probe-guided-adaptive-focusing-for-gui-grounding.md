## 摘要
GUI 定位需要在赋予其意义的上下文中分辨细粒度视觉细节。额外视图可以改善定位，但其价值取决于它们揭示了何种证据以及保留了多少上下文。我们探索了视觉语言模型（VLM）的一种能力：即使其坐标预测不正确，它们也能描述值得检查的视觉证据。我们提出 SPARK（Semantic Probe-guided Adaptive Region seeKing，语义探针引导的自适应区域查看），一个无需训练的框架，将这种语义引导转化为有针对性的视觉观察。探索探针描述相关上下文和有区分度的目标细节，而验证探针识别评估新出现假设所需的证据。它们的空间注意力引导视图放置，上下文响应决定裁剪范围，观察历史鼓励互补性检查。最终预测通过不确定性加权投票进行融合。在 ScreenSpot-Pro 上，SPARK 使用 Qwen3-VL、Qwen2.5-VL 和 UI-TARS 时，将定位准确率相较单视图推理分别提升 13.9、25.2 和 16.1 个百分点，并在每个骨干模型上优于所有对比的测试时方法。在另外四个基准上的稳定增益表明，它在多样界面和定位任务上均有效。这些结果确立了语义探针作为一种有效机制，可将冻结 VLM 对“该检查什么”的理解转化为更准确的 GUI 定位。

## Abstract
GUI grounding requires resolving fine visual details within the context that gives them meaning. Additional views can improve localization, but their value depends on what evidence they expose and how much context they preserve. We explore a capability of vision-language models (VLMs): even when their coordinate predictions are incorrect, they can describe visual evidence worth inspecting. We introduce \textbf{SPARK}, \textit{\textbf{S}emantic \textbf{P}robe-guided \textbf{A}daptive \textbf{R}egion see\textbf{K}ing}, a training-free framework that turns this semantic guidance into targeted visual observations. Exploration probes describe relevant context and distinguishing target details, while verification probes identify evidence needed to assess emerging hypotheses. Their spatial attention guides view placement, contextual responses determine crop extent, and observation history encourages complementary inspection. The resulting predictions are combined through uncertainty-weighted voting. On ScreenSpot-Pro, SPARK improves grounding accuracy over single-view inference by 13.9, 25.2, and 16.1 percentage points with Qwen3-VL, Qwen2.5-VL, and UI-TARS, outperforming all compared test-time methods for each backbone. Consistent gains across four additional benchmarks demonstrate its effectiveness across diverse interfaces and grounding tasks. These results establish semantic probing as an effective mechanism for turning a frozen VLM's understanding of what to inspect into more accurate GUI grounding.

## 1. 核心问题与研究动机

- **任务背景**：GUI grounding 要求将自然语言指令映射到屏幕上的精确坐标。在复杂专业界面中，目标往往需要结合功能上下文才能分辨细粒度视觉差异。
- **核心矛盾**：宽视图保留上下文但细节模糊；近视图细节清晰却可能丢失解释该细节所需的面板/地标。因此有效定位不仅要知道“点哪里”，还要决定“看哪里、以什么尺度看、检查什么证据”。
- **现有方法局限**：基于视图的方法（RegionFocus、DRS-GUI 的 zooming，MVP 的多视图）虽能暴露细节，但额外视图的价值取决于所选区域与保留上下文；重复观察相似区域收益低，过度紧裁剪会丢失判别信息。
- **关键观察（论文出发点）**：VLM 即使坐标预测错误，仍能描述“值得检查的视觉证据”。例如图 1 中模型误点相邻的“LF”控件，却正确指出应检查“UTF-8”编码指示器。这说明**语义层面的检查指引可以先于准确定位出现**。
- **研究问题**：VLM 能否自己指出下一步该检查什么，从而改进 GUI grounding？
- **整体含义**：提出 SPARK，将冻结 VLM 的“该检查什么”转化为有针对性的局部观察，连接语义理解与空间定位，且无需训练。

## 2. 方法论

### 2.1 核心思想

- 用**语义探针（semantic probe）**——简短、任务条件化的视觉证据描述——同时获得两类信息：
  - **语义层面**：要寻找什么证据；
  - **空间层面**：描述 token 对应的视觉注意力图，指示证据可能位于何处。
- 通过注意力把“检查什么”翻译为“在哪看、看多大范围”，并用观察历史鼓励互补视图，最后用不确定性加权投票融合多次预测。

### 2.2 分层语义探针

- **层级结构**：`Context`（相关面板/区域与可见地标）与 `Detail`（区分目标控件的局部细节），连接“赋予意义的上下文”与“区分目标的特征”。
- **探索探针（Exploration Probe）**：输入全截图与指令，输出 Context 与 Detail，表达“去哪找、找什么”。
- **验证探针（Verification Probe）**：额外输入带假设标记的截图（前两个最高分预测簇的 medoid，或单簇时的唯一 medoid），输出 `Control`（目标控件）、`Context`（周边环境）、`Inspect`（验证身份/功能所需的具体可见细节）。候选标签按空间顺序排列，提示模型不要假定标记正确。
- 两类探针共享 context-to-detail 层级，使语义指引随观察演化。

### 2.3 从语义探针到空间引导

- 对探针描述的内容 query 位置，取各层各头上对视觉 token 的注意力，按 head 取最大值、按 query 取平均并归一化，得到空间图：
  - 探索：`(C^E, D^E)`；
  - 验证：`(C^V, I^V)`。
- 视觉 token 中心按实际预处理网格映射回原图坐标。
- 从 `C^E`、`D^E` 及初始全局定位注意力 `A^G` 的 top-K 位置构建共享候选窗口池，去除重复矩形；两类探针按各自图对选择候选。

### 2.4 自适应视图构建

- **历史覆盖折扣**：对已被历史视图覆盖的区域按系数 ρ 折扣注意力，鼓励空间互补，同时允许必要时重访。
- **窗口评分**：区域内折扣后的 Context 与 Detail（或 Context 与 Inspect）响应求和，取**几何平均**作为得分，选择得分最高的标准窗口，使窗口同时受上下文与局部证据支持。
- **尺度自适应**：以未折扣的探索 Context 图作为尺度选择的持久参考，计算锚点周围的局部加权上下文质量；在 `[0.7, 1.4]` 范围内选择**最小尺度**，使其保留最大参考窗口上下文质量的 τ=0.9。证据集中→更紧视图；上下文分散→更大观察范围。
- 选定区域按视觉 token 预算裁剪并加入历史；初始局部视图由全局定位注意力初始化并计入视图预算。
- **流程（Algorithm 1）**：全局定位 → 初始局部视图 → 探索探针 → 构建候选池 → 循环“聚焦-观察” → 第二次观察后基于聚类假设触发验证探针 → 继续聚焦观察 → 最终聚合。

### 2.5 不确定性加权投票

- 对每个预测，计算生成 token 的平均预测熵作为不确定性。
- 权重 `w_t = exp(-(H̄_t - H̄_min)/T)`，T=0.3。
- 用完整链接聚类（ε=14 像素）按观察顺序聚合预测；簇得分为成员权重之和，取最高分簇。
- 最终坐标取获胜簇的**空间 medoid**，保留一个实际观测点并代表空间共识。
- 全局与局部预测共同参与聚合。
