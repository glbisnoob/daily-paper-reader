## 摘要
小型图形用户界面（GUI）智能体能够执行桌面工作流，但重复的局部错误和脆弱的过程性决策限制了其可靠性。我们提出 GUI-WEdit-4B 和 GUI-SkillEvo-2B，这是对 GUI-Owl-1.5 主干网络的两种无梯度适配。对于 4B 模型，我们利用轨迹反馈对后段多层感知机（MLP）构造带保护的闭式更新，并将成功状态保留为保护约束。最终检查点在一个权重张量内改变了 23,739,095 个参数值，占 4,437,815,808 参数主干网络的 0.535%。对于 2B 模型，由助手迭代提出并改进过程性技能，而模型权重保持不变。在 OSWorld 的 361 项任务子集（排除 Google Drive 任务）上，冻结系统分别获得 48.02% 和 45.47% 的最终综合得分。

## Abstract
Small graphical user interface (GUI) agents can execute desktop workflows, but repeated local errors and fragile procedural decisions limit their reliability. We present GUI-WEdit-4B and GUI-SkillEvo-2B, two gradient-free adaptations of GUI-Owl-1.5 backbones. For the 4B model, we use trajectory feedback to construct guarded, closed-form updates to a late multilayer perceptron (MLP), retaining successful states as protection constraints. The final checkpoint changes 23,739,095 parameter values, or 0.535\% of the 4,437,815,808-parameter backbone, within one weight tensor. For the 2B model, an assistant iteratively proposes and refines procedural skills while the model weights remain fixed. On the 361-task OSWorld subset excluding Google Drive tasks, the frozen systems obtain final aggregate scores of 48.02\% and 45.47\%, respectively.

  - 目标构造：固定指令、截图、历史与前置响应 token，采集 MLP 输入和残差激活；由期望 token 的读出边际定义目标激活列 \(K\) 上的残差校正 \(U\)。

    \[
    \min_{\Delta W}\sum_{j\in G}\frac{\|\Delta W g_j\|_2^2}{\|h_j\|_2^2}+\lambda\|\Delta W D^{-1}\|_F^2,\quad \text{s.t. }\Delta W K=U

    \[
    \Delta W=U(K^T C^{-1}K)^{-1}K^T C^{-1}

### 6. 主要结论与发现
- 两种无梯度适配均带来提升：4B 最终 48.02%，较历史参考提升 4.59 个百分点；2B 最终 45.47%，提升 7.79 个百分点。
- 4B 仅修改一个末端 MLP 张量中的约 0.535% 参数，说明高度局部化的权重编辑即可产生可测行为改善。
- 2B 在完全冻结权重的情况下，通过技能库获得更大相对提升，表明程序性上下文是小型 GUI 智能体的有效适配点。
- 领域差异明显：4B 在 GIMP 80.77%、VS Code 69.57%、Writer 56.51% 较好；2B 在 Thunderbird 93.33%、操作系统任务 91.67%、VS Code 69.57% 较好。多应用工作流和 LibreOffice Calc 对两者均较困难。
- 4B 相对历史参考呈“少数提升、少数下降、多数持平”的分布，说明局部编辑影响集中且并非全面提升。
