## Abstract 

Graphical user interface (GUI) agents translate screen-shots and user instructions into executable actions. Most existing approaches rely on vision-language models to gen-erate actions as text, often leading to substantial infer-ence latency due to autoregressive decoding. To address this inefficiency, we propose GUI-PRISM, a hybrid action decoder that directly predicts action types and structured arguments while retaining language generation for open-ended text. Unlike existing spatial decoding methods that primarily focus on target localization, GUI-PRISM extends direct prediction to action types and their associated argu-ments, enabling complete GUI action prediction. Specif-ically, GUI-PRISM employs field-specific queries to ex-tract action-relevant semantic and spatial information from a shared multimodal feature bank. It further models de-pendencies among action components through conditional queries. Gated residual cross-attention refines these pre-dictions using fine-grained multimodal information. GUI-PRISM achieves 95.1% accuracy on ScreenSpot-v2, outper-forming the strongest head-based spatial decoding method by 2.0 percentage points while delivering a 3.8 × inference speedup over the baseline. On AndroidControl-v2 and MM-Mind2Web-v2, it improves complete-action accuracy by 4.8 and 0.7 percentage points while achieving 2.7 × and 3.9 ×

inference speedups over the baseline, respectively. Our code is available on our project page.

Recent advances in vision-language models (VLMs) have substantially improved GUI action prediction, enabling agents to interpret diverse instructions, identify in-teraction targets, and generate complete actions across dif-ferent interfaces [20, 26, 36]. Despite these advances, generating GUI actions as text introduces substantial autoregressive decoding overhead, as illustrated in Fig. 1(a). Models must sequentially gener-ate both schema formatting tokens, such as field names ‘action type, value, x, y ’ and delimiters such as ‘", :, {, }’, and action content, including action type ‘Write ’, the text value ‘ hello ’, and coordinate values ‘320, 180 ’. Recent spatial decoding methods primarily focus on im-proving target localization through specialized visual rep-resentations and spatial decoding mechanisms [4, 15, 30]. However, complete GUI action prediction requires handling a broader range of outputs, including action types, target coordinates, discrete arguments, and open-ended text. This motivates a hybrid decoding approach that combines direct prediction of structured action components with language generation for open-ended text. Realizing this approach presents two key challenges. (1) Extracting field-specific multimodal information: Differ-ent prediction heads require distinct information from the same screenshot and instruction. For example, clicking the ‘ Save ’ button requires determining the intended ac-tion and precisely locating its target. These differing in-formation requirements make it difficult for each prediction head to selectively extract the action-relevant semantic or spatial information it needs from shared multimodal rep-resentations. (2) Preserving dependencies in direct action decoding: Unlike autoregressive generation, which natu-rally conditions subsequent tokens on preceding outputs, direct prediction does not inherently capture dependencies among action components. The predicted action type deter-mines the required arguments, while coordinate prediction involves dependencies between the horizontal and vertical axes. The challenge is to preserve these relationships with-out reverting to token-by-token generation. In this paper, we propose GUI-PRISM, a hybrid action decoder that directly predicts action types and structured arguments while retaining language generation for open-ended text values when required, as illustrated in Fig. 1(b). Specifically, GUI-PRISM introduces field-specific queries to extract action-relevant semantic and spatial information from a shared PRISM feature bank integrating visual, con-textual, and action-relevant features. We explicitly model dependencies among action components: the predicted ac-tion type determines the applicable arguments and their cor-responding predictors, while coordinate queries incorporate the selected action type and the initial horizontal-coordinate estimate. We further employ gated residual cross-attention to refine these predictions using fine-grained action-relevant and visual information from the shared PRISM feature bank. Together, these designs enable GUI-PRISM to pre-dict complete GUI actions while preserving dependencies among structured action components. GUI-PRISM achieves 95.1% accuracy on ScreenSpot-v2, outperforming the strongest head-based spatial de-coding method by 2.0 percentage points while deliver-ing a 3.8 × inference speedup over the baseline. On AndroidControl-v2 and MM-Mind2Web-v2, it improves complete-action accuracy by 4.8 and 0.7 percentage points

## 2. Related Work 

GUI agents. GUI agents translate visual observations and user instructions into executable actions. Early ap-proaches develop screenshot understanding and visual grounding through multimodal pretraining and large-scale GUI data [6, 9, 12, 31]. Subsequent methods learn action prediction from interaction demonstrations, incorporating task context and intermediate reasoning to support opera-tion selection and target localization [22, 26, 29, 35]. Rein-forcement learning further improves agent behavior through feedback on action correctness and task outcomes [10, 36, 37]. These advances primarily improve the capabilities and training of GUI policies, while many approaches still express actions as autoregressively generated text. GUI-PRISM focuses on the action decoder, directly predict-ing structured fields and retaining language generation for open-ended text values.

Structured prediction. Query-based decoders provide a general mechanism for extracting output-specific informa-tion from shared features. 3.2. Hybrid Action Decoding 

GUI-PRISM constructs a shared feature bank and employs dependent field queries to predict complete GUI actions, al-lowing preceding predictions to guide subsequent fields. 

PRISM Feature Bank. Accurate GUI action prediction requires complementary visual, contextual, and action-relevant information. To make these information sources available for different action fields, we construct a shared PRISM feature bank that integrates their representations. Let P denote the input prefix containing the observable multimodal input and inherited learned context positions. We introduce six learnable embeddings EA to capture com-plementary action-relevant information for prediction. Pro-cessing [P ; EA] through the VLM backbone yields contex-tual states HC from the inherited context positions, action-relevant states HA from the additional embeddings, and vi-sual states HV from image-token positions. Each feature group is mapped to Mr = ϕr (Hr ) for 

r ∈ { C, A, V }, where ϕr incorporates layer normalization (LN), feature projection, and feature-type embeddings. The resulting feature bank is 

M = [ MC ; MA; MV ] ∈ RN ×d, d = 1024 , (2) where N denotes the total number of feature positions. The feature bank is computed once per input and shared across field predictions, with padding masked. 

Dependent Field Queries. While the shared PRISM fea-ture bank provides multimodal information, different action fields require distinct information and exhibit dependencies during prediction. To address these requirements, we con-struct three dependent field prompts Qc, Qx, and Qy for op-eration and coordinate prediction. The coordinate prompts incorporate the selected operation, while Qy additionally includes the initial X estimate. 3.3. Training 

To jointly optimize structured action prediction and open-ended text generation, we train GUI-PRISM with comple-mentary supervision objectives. 

Action prediction supervision. We use cross-entropy losses Ltype , Lx, and Ly to supervise operation types and coordinate bins. Additional cross-entropy losses super-vise coordinate presence ( Lpres ), finite-valued arguments (Lfinite ), and coordinate permission ( Lpointer ). The auxil-iary loss is 

Laux = λpLpres + Lfinite + Lpointer , (8) where λp = 0 .25 . The action-head objective is 

Lhead = Ltype + m(Lx + Ly ) + Laux , (9) where m ∈ { 0, 1} indicates whether the ground-truth action contains a target coordinate. 

Joint optimization. The main training objective com-bines action prediction and language generation: 

Ljoint = λhLhead + λLLLM , (10) where λh = λL = 1 are the loss weights, and LLM super-vises native action serialization.

## 5. Conclusion 

In this paper, we propose GUI-PRISM, a hybrid action de-coder for efficient and accurate GUI action prediction. GUI-PRISM directly predicts action types and structured argu-ments while retaining language generation for open-ended text. It constructs a shared PRISM feature bank from vi-sual, contextual, and action-relevant features. Field-specific queries extract action-relevant semantic and spatial infor-mation from this bank, while conditional queries model de-pendencies among action components by using preceding predictions to guide subsequent ones. Gated residual cross-attention further refines these predictions using fine-grained multimodal information. Experiments on GUI grounding and offline action prediction benchmarks demonstrate that GUI-PRISM improves prediction accuracy while reducing inference latency, supporting efficient decoding of complete GUI actions across diverse tasks and interface settings.
