## 摘要
GUI智能体可以在推理中制定出正确的即时计划，却输出一个无法执行该计划的动作，从而形成执行鸿沟。这种反复出现的不匹配会损害可靠的任务完成，因为单次执行错误就可能使多步工作流偏离正轨。在结果监督强化学习中，将负的响应级优势广播到所有生成token上，可能会在惩罚错误执行的同时也惩罚有效规划。为解决这一信用分配冲突，我们提出PACT（Plan-Action Consistency Training，计划-动作一致性训练），该训练框架在不改变原始标量动作奖励的情况下，结合了参考对齐的计划保护与计划对齐的动作修复。PACT利用标注的参考动作来识别执行鸿沟，并通过在其token跨度上屏蔽负的策略梯度贡献来保护已验证的计划。在将生成的推理保持不变作为上下文的情况下，PACT随后通过带有停止梯度成对权重的偏好替代目标，使参考动作相对于已输出的错误动作更受偏好。与仅使用结果的基线相比，PACT将AndroidWorld的任务成功率从60.34%提升至68.97%（+8.63个百分点），同时将AndroidControl High上基于规则的计划-动作一致性从83.71%提升至89.74%（+6.03个百分点）。将PACT适配到桌面智能体后，在完整的369项任务OSWorld基准上，任务成功率也从40.92%提升至44.17%（+3.25个百分点）。总之，这些结果表明，PACT是一个有效的信用分配框架，能够弥合执行鸿沟，并提升移动端和桌面端GUI环境中的任务完成表现。

## Abstract
GUI agents can formulate a correct immediate plan in their reasoning yet emit an action that fails to execute it, creating an execution gap. This recurring mismatch undermines reliable task completion, as a single execution error can derail a multi-step workflow. In outcome-supervised reinforcement learning, broadcasting a negative response-level advantage across all generated tokens risks penalizing valid planning together with erroneous execution. To address this credit-assignment conflict, we introduce PACT (Plan-Action Consistency Training), a training framework that combines reference-aligned plan protection and plan-aligned action repair without altering the original scalar action reward. Using annotated reference actions to identify execution gaps, PACT protects the verified plan by masking negative policy-gradient contributions across its token span. Keeping the generated reasoning unchanged as context, it then favors the reference action over the emitted erroneous action through a preference surrogate with stop-gradient pair weights. Compared with the outcome-only baseline, PACT raises AndroidWorld task success from 60.34% to 68.97% (+8.63 pp), while improving rule-based plan-action consistency on AndroidControl High from 83.71% to 89.74% (+6.03 pp). Adapting PACT to desktop agents also improves task success from 40.92% to 44.17% (+3.25 pp) on the full 369-task OSWorld benchmark. Together, these results establish PACT as an effective credit-assignment framework for bridging execution gaps and improving task completion across mobile and desktop GUI environments.

# PACT 论文深度总结

## 1. 核心问题与研究动机

- **执行鸿沟（Execution Gap）**：GUI 智能体在推理文本中往往能给出正确的“即时计划”（如“点击 + 按钮”），但最终输出的动作却与该计划不符（如发出 `LaunchApp`）。这与“规划错误”不同——响应中已含有效计划，只是动作未能实现它。由于 GUI 任务是闭环多步的，一次执行错误即可让整条工作流失败。
- **信用分配冲突**：主流做法是在 GRPO 等结果监督 RL 中，把一个**响应级标量优势**广播到所有 token。当响应失败时，负优势会同时惩罚“正确的规划 token”和“错误的动作 token”，即“连坐”。
- **标量一致性奖励的盲区**：已有工作（如 Faithful-Agent）使用 thought–action 一致性奖励，但标量奖励**无法决定修正方向**——模型可以改计划去迁就错误动作，也可以“一致地执行一个错误计划”，一致性升高不等于正确性提升。
- **论文主张**：应当做**选择性信用分配**——保留参考动作所支持的有效计划，只修复未能实现它的动作，且**不修改原始标量动作奖励**。

## 2. 方法论：PACT 框架

### 2.1 核心思想
在 group-relative RL 流水线内，用标注的参考动作 a⋆ 判定“计划正确但动作错误且不一致”的执行缺口，然后并行施加两个互补机制：**参考对齐的计划保护**（屏蔽计划 span 的负梯度）与**计划对齐的动作修复**（在同一推理上下文下偏好参考动作后缀）。

### 2.2 判定体系与选择器
- 定义三个二元判据：**T**（当前计划对任务正确）、**A**（动作对当前状态有效）、**C**（动作实现了所述计划）；四类正确性情形分别对应不同训练含义（T=1,A=0 才触发保护+修复；T=0 时不做强制计划对齐，以免把有效动作拉去服从错误计划）。
- 执行缺口资格：`E_i = J_i · 1[ T̂=1, Â=0, Ĉ=0 ]`，其中 J_i 为“可判定性”（需可解析参考动作、唯一动作块、非终止计划、参数可核查）。
- 规则化提取：反向扫描推理的**最后四句**寻找显式即时计划，排除否定、多步歧义与动作类型冲突；计划只从推理文本抽取，**绝不从已生成动作反推**。点按需唯一显式坐标，滚动需单一方向，输入/启动需唯一引号参数。
- 不可判定样本（J_i=0）仍留在基础 RL 目标中，仅不参与辅助监督。

### 2.3 保留原始动作奖励
- 沿用原评分器：`R0 = r_fmt + 1[τ(a)=τ(a⋆)]·(1 + P0(a,a⋆))`，其中参数分对点按用像素距离阈值（0.07m 得 1.0、0.14m 得 0.5），滑动检查双端点，文本类用精确匹配或 token-F1>0.5。
- GRPO 组标准化优势 `A0_i = (R0,i − μ_g)/(s_g + 1e−6)`；**修复用的构造样本不进入 rollout 组，不影响 μ_g、s_g**。

### 2.4 参考对齐的计划保护
- 将已验证计划的字符 span 映射到 token 索引得到掩码 `M^D`，修改 token 级优势：
  - 计划 span 内：`Ã = max(A0, 0)`（**只把负系数截零，正优势保留**）
  - 其他位置：`Ã = A0`（动作 token、其余推理 token 不变）
- 关键性质：只作用于**局部策略梯度系数**，不冻结共享参数、不屏蔽 KL 正则、不重归一化组优势。

### 2.5 计划对齐的动作修复
- 构造正样本 `y+ = (z_i, a⋆_i)`：**只替换 `<action>` 块**，输入与解码出的推理 z_i 原样保留作为共享条件。
- 动作 span 对数概率 `s± = Σ M^A · log πθ(y±|x, y±<t)`，仅动作 tag 与动作 token 计入。
- 冻结成对权重（stop-gradient）：
  `w_i = (λβ/B0) · σ( β[ s−_old − s−_ref − s+_old + s+_ref ] )`，B0 为原始 rollout 批大小而非配对数。
- 替代损失：`L_repair = Σ_{i∈P} stopgrad(w_i)(s−_θ − s+_θ)`；文中证明其在 θ_old 处的梯度**等价于条件 DPO 逻辑偏好目标的一阶梯度**，从而以线性替代形式复用冻结权重。
- 总目标：`L_actor = L_PG(Ã, B) + η·L_KL + L_repair`；正样本只进 L_repair，不进 rollout 批与 KL 项。
- **推理阶段完全不变**：标准单次 reasoning→action 接口，无额外反思或重规划。
