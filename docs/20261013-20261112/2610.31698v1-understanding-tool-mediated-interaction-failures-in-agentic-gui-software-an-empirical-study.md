## 摘要
大型语言模型（LLM）智能体越来越多地通过实时图形用户界面（GUI）完成任务。由于模型无法直接操作GUI，这些系统通常依赖工具来捕获屏幕截图或UI树、将模型输出转换为GUI动作，并报告界面是否发生变化。我们研究此类工具介导的交互导致智能体对任务的理解与实时GUI产生偏差的失败。我们构建了Malva，一个缺陷库，包含来自40个开源应用的335个已确认真实世界失败。这些失败归为11种缺陷模式，根源在于状态表示、状态转换和同步问题。它们广泛存在：所研究应用中90%包含不止一种缺陷类型。它们也常常是静默的：86.6%的失败中出现不正确性，包括119个案例在没有故障停止信号的情况下产生错误行为。我们用MalvaGuard将这一分类体系操作化，这是一个部署前静态契约检查器，在额外的20个应用语料上达到57.3%的精确率和76.8%的召回率。

## Abstract
Large language model (LLM) agents increasingly complete tasks through live graphical user interfaces (GUIs). Because the model cannot directly operate the GUI, these systems often rely on tools to capture screenshots or UI trees, translate model outputs into GUI actions, and report whether the interface changed. We study failures where this tool-mediated interaction makes the agent's view of the task diverge from the live GUI. We construct Malva, a defect library with 335 confirmed real-world failures from 40 open-source applications. These failures fall into 11 defect patterns rooted in state representation, state transition, and synchronization problems. They are widespread: 90% of the studied applications contain more than one defect type. They are also often silent: incorrectness appears in 86.6% of failures, including 119 cases that produce wrong behavior without a fail-stop signal. We operationalize this taxonomy with MalvaGuard, a pre-deployment static contract checker that reaches 57.3% precision and 76.8% recall on an additional 20-application corpus.
