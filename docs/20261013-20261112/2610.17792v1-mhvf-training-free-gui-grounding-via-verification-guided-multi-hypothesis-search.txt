## Abstract 

GUI grounding enables web agents to translate natural-language instructions into actionable interface locations. However, dense layouts and small, visually similar controls can lead models toward plausible but incorrect elements, while refinement around a single prediction may leave alternative targets unexplored. We propose the Multi-Hypothesis Verification Framework (MHVF) for training-free GUI grounding. It combines multi-hypothesis exploration with local visual verification using a single pretrained vision-language model. To explore alternative targets, MHVF constructs spatial hy-potheses from multiple full-screen predictions and examines the corresponding regions through zoomed re-localization. To resolve ambiguity among the resulting candidates, it verifies their agree-ment with the instruction in marked local views. Verification scores then guide a second round of local search and rank candidates re-tained from both search levels for final selection. Experiments with five general-purpose and GUI-specific models across eight bench-mark settings demonstrate improvements in grounding accuracy in most settings. MHVF improves UI-Venus-Ground-7B by 4.3 and 2.1 percentage points on Mind2Web and VisualWebBench, respec-tively, and raises Qwen2.5-VL-7B’s accuracy on ScreenSpot-Pro from 23.6% to 53.6%.

## 1 Introduction 

Web agents rely on GUI grounding to translate natural-language instructions into clicks on the intended interface elements. Vision-language models (VLMs) enable this process directly from screen-shots, but grounding remains a major obstacle to reliable web inter-action [42]. Dense page layouts, small controls, and visually similar elements make precise localization challenging, particularly when fine details are lost at the model’s input resolution [20]. Figure 1(a) illustrates such a failure: given an instruction to select a product’s comparison checkbox, the model clicks the product image. Recent training-free approaches improve GUI grounding through zooming, multi-view prediction, and candidate comparison. Zoom-Click investigates staged zooming, MVP aggregates predictions across multiple views, and AutoFocus combines region proposals with visual candidate comparison [8, 38, 40]. Magnification pro-vides finer visual evidence, but successful grounding also requires inspecting regions that contain the target and choosing a candi-date that matches the instruction. Initial predictions can guide this exploration by suggesting several possible target locations, while

verification can assess the candidates obtained through local in-spection. This motivates using local visual verification to connect candidate assessment with subsequent region search and final se-lection. To this end, we propose the Multi-Hypothesis Verification Frame-work (MHVF) for training-free GUI grounding. It combines multi-hypothesis search with local visual verification using a single pre-trained VLM. At the first level, multiple full-screen predictions iden-tify potential target regions for inspection. The model re-localizes the target in magnified views of these regions and verifies whether each candidate matches the instruction. To focus additional ex-ploration, MHVF reopens the region associated with the highest-scoring candidate for a second round of hypothesis generation, re-localization, and verification. Candidates from both levels are re-tained, and the point with the highest verification score is selected as the final click. We conduct extensive experiments with general-purpose and GUI-specific models across web, desktop, and cross-platform inter-faces. The evaluation covers web grounding on Mind2Web and Visu-alWebBench, high-resolution professional interfaces on ScreenSpot-Pro, and cross-platform grounding on MMBench-GUI L2, among other benchmarks. The results show that MHVF improves the grounding accuracy of existing models in most evaluated settings. Our main contributions are summarized as follows: 

• We propose MHVF, a training-free framework for GUI grounding that explores multiple spatial hypotheses and verifies the resulting candidates using a single pretrained VLM. 

• We develop a two-level search mechanism that uses local verification scores to guide region reopening and select the final click from candidates retained across both levels. 

• We evaluate MHVF on five models across eight benchmark settings covering web, desktop, and cross-platform inter-faces, demonstrating improved grounding accuracy in most settings. 

## 2 Related Work 2.1 Web Agents and GUI Grounding 

Web agents use vision-language models to interpret interfaces and translate user instructions into executable actions. SeeAct inves-tigates this process by separating action generation from ground-ing actions to web elements [42]. To support interaction directly from screenshots, subsequent research develops models that map natural-language instructions to target locations. SeeClick intro-duces grounding-oriented pretraining with automatically collected data, while UGround and OS-Atlas expand grounding data and model capabilities across web, desktop, and mobile interfaces [2, 6, 33]. These efforts provide the grounding capabilities on which MHVF builds, with our focus on improving existing models through inference-time search and verification. 

## 2.2 Test-Time Scaling for GUI Grounding 

Test-time scaling improves grounding by allocating additional com-putation to visual inspection and prediction. One line of work explores how to select and examine informative screenshot re-gions. ZoomClick studies staged zooming and the effects of ini-tialization, search depth, and context retention, while DRS-GUI uses Monte Carlo Tree Search to plan region-level perceptual ac-tions [8, 21]. Adaptive methods further use model predictions to determine when and where to zoom. UI-Zoomer combines spa-tial consensus with generation confidence to trigger zooming and derives crop sizes from prediction uncertainty [28]. AutoFocus uses visual self-verification to decide whether refinement is needed, then constructs region proposals from spatial uncertainty estimated through sampled coordinate predictions [38]. A related line of work examines how to aggregate or assess multiple predictions. GUI-RC identifies consensus regions through spatial voting over sampled predictions, while MVP aggregates predictions from attention-guided views and selects the centroid of the densest spatial cluster [4, 40]. Other approaches use visual reasoning to compare candidates. DiMo-GUI generates candidates through separate text and icon grounding paths and selects between them using the instruction and full-resolution screenshot [32]. Aut-oFocus jointly compares images annotated with candidate locations to determine the final prediction [38]. MHVF assesses candidates individually in magnified local views using the same grounding model. Its verification scores guide both the choice of a region to re-open for further exploration and the final selection from candidates retained across two search levels. 

## 3 Method 3.1 Problem Formulation 

Given a GUI screenshot 𝐼 and a natural-language instruction 𝑞 , GUI grounding aims to predict a click position 𝑝 = (𝑥, 𝑦 ) ∈ [ 0, 1]2 on the interface element specified by 𝑞 . Coordinates are normalized with respect to the original screenshot. We use a frozen pretrained vision-language model 𝐺 as the base grounder. A view 𝑣 is either the full screenshot or a local region obtained through cropping and resizing, with 𝑣 0 denoting the full-screen view. A spatial hypothesis specifies a region for further in-spection. A candidate click is a position obtained by re-localizing the target within the corresponding local view and mapping the prediction back to the original screenshot. 

## 3.2 Overview of MHVF 

As illustrated in Figure 2, MHVF organizes grounding into two search levels. At level 1, the model produces multiple full-screen predictions, which are grouped into spatial hypotheses ( P). Each hypothesis determines a region to crop and magnify, allowing the model to re-localize the target with more detailed visual evidence (Z). The resulting candidate is then marked in its local view and assessed against the instruction ( V ). At level 2, MHVF reopens the view associated with the highest-scoring first-level candidate ( R). The model generates new hypothe-ses within this view and applies the same localization and verifi-cation procedure to obtain additional candidates. Candidates from both levels remain available for final selection, and MHVF returns the click with the highest verification score. The same model per-forms hypothesis generation, localization, and verification through-out the process.

## 4.2 Main Results 

Performance on Web Benchmarks. MHVF improves four of the five models on each web benchmark (Table 1). On Mind2Web, the gains range from 2.7 to 5.3 percentage points for these models; UI-Venus-Ground-7B improves from 75.7% to 80.0%. The improve-ments extend across all three test splits for Qwen2.5-VL-7B and UI-Venus-Ground-7B under both instruction formats (Table 2). With task instructions, the largest gains occur on the cross-website split, reaching 14.1 and 8.8 points, respectively. VisualWebBench shows smaller gains, with UI-Venus-Ground-7B improving from 90.7% to 92.8%. GTA1-7B is the exception on both web benchmarks, indicat-ing that additional search does not benefit every grounding model equally. 

Performance on Desktop and Cross-Platform Benchmarks. The improvements also hold on ScreenSpot-Pro, OSW-G, OSW-GR, UI-Vision, and WinDeskGround, where all five models benefit (Table 1). ScreenSpot-Pro shows large gains for both general-purpose and GUI-specific models: Qwen2.5-VL-7B improves from 23.6% to 53.6%, while UI-Venus-Ground-7B improves from 50.3% to 66.6%. The lat-ter also improves from 26.7% to 38.8% on UI-Vision. These results extend the web findings to professional desktop interfaces and other GUI domains. Improvements are smaller on WinDeskGround and MMBench-GUI L2 for GUI-specific models; GTA1-7B decreases from 79.6% to 76.5% on MMBench-GUI L2.

## 4.3 Ablation Study 

Table 4 evaluates the components of MHVF on Mind2Web and ScreenSpot-Pro. Both multiple hypotheses and magnification con-tribute to accuracy. Using a single initial hypothesis reduces ac-curacy by 0.8 points on Mind2Web and by 2.5 and 6.4 points on ScreenSpot-Pro for UI-Venus-Ground-7B and Qwen2.5-VL-7B, re-spectively. Removing magnification ( 𝜅 = 1) while retaining crop-ping produces larger drops on ScreenSpot-Pro, at 5.0 and 12.5 points. This comparison shows that increasing the visual scale of a selected region helps beyond cropping alone, particularly on high-resolution interfaces. Verification also helps when the search depth is held fixed. Com-paring the two variants without reopening, verification raises ac-curacy over ranking by hypothesis weight from 78.9% to 79.7% on Mind2Web and from 61.9% to 65.5% and 45.7% to 50.9% on ScreenSpot-Pro. Reopening adds a further 0.3, 1.1, and 3.0 points, re-spectively, with a modest improvement on Mind2Web. Full-screen verification yields losses of 0.4–1.6 points relative to zoomed-view verification, with no statistically significant difference for Qwen2.5-VL-7B on ScreenSpot-Pro or UI-Venus-Ground-7B on Mind2Web. Thus, verification provides a clearer benefit than the choice of its input view, while the value of reopening varies across settings.

## 5 Conclusion 

We presented MHVF, a training-free framework that combines multiple spatial hypotheses with local visual verification for GUI grounding. Using a single pretrained VLM, MHVF explores po-tential target regions, re-localizes candidates in magnified views, and uses verification to guide local refinement and final selection. Experiments with five models across eight benchmark settings demonstrate improved accuracy in most settings, covering web, desktop, and cross-platform interfaces. Candidate-level analyses show that local search expands target coverage, while selecting the correct candidate remains a source of error. This gap, together with the additional visual input cost, motivates further work on more reliable candidate verification and adaptive allocation of the search budget. (a) Level-1 localization

## A Implementation Details and View Geometry 

Search settings. Spatial clustering uses 𝛿 = 2 merged visual to-kens. We set 𝛽 = 3 at both levels, with crop floors 𝜌 = 0.25 and 

𝜌 ′ = 0.10, and reopen one region. GTA1-7B point predictions re-ceive centered boxes spanning 1.5% of the input view along each axis, clipped before mapping to screenshot coordinates. Localization uses greedy decoding with at most 32 output tokens. 

Verification implementation. The point-verification prompt is: “The red circle marks one UI element. Is the circled element the one described as ‘ instruction ’? Answer Yes or No.” We request one output token and the top-20 log-probabilities. Each label score is the maximum over its available single-token variants, including capitalization and leading spaces; absent labels receive −30. These estimates are used in Eq. (7) to rank candidates without an accep-tance threshold. The ring size follows the predicted box extent and is bounded relative to the view dimensions.
