## 摘要
计算机使用智能体在数字世界中执行复杂任务的能力日益增强。为推进此类智能体发展，基于标注交互轨迹的监督学习已成为提升其任务求解能力的常用方法。然而，对于专用桌面应用，高质量交互轨迹仍然稀缺；有限的应用知识、复杂的 GUI 工作流以及不充分的探索阻碍了自动化收集。为解决这些挑战，我们提出 \aks{}，一个知识引导的自动化轨迹收集框架。它结合教程引导的探索与 GUI-代码混合动作空间，提供应用特定知识，并通过直接执行应用原生命令来简化 GUI 工作流。该框架还在树探索过程中对关键状态设置检查点并重访，以探索替代工作流，补充线性 rollout 以实现更广覆盖。我们收集了 10.9K 条自动验证的轨迹，并用其微调开源基础模型。所得模型在专用桌面工作流基准上达到 64.1% 的准确率，性能提升 58.2 个百分点，确立了新的最先进水平。微调后的模型在仅使用 GUI 操作的通用桌面工作流上也提升了性能，表明收集到的监督信号同样有益于通用桌面任务。对比实验和消融实验证明了我们收集框架的效率以及代码动作在专用工作流中的价值。

## Abstract
Computer-using agents are increasingly capable of performing complex tasks in the digital world. To advance such agents, supervised learning on annotated interaction trajectories has become a common approach to improving their task-solving capabilities. However, high-quality interaction trajectories remain scarce for specialized desktop applications, where limited application knowledge, complex GUI workflows, and incomplete exploration hinder automated collection. To address these challenges, we introduce \aks{}, a knowledge-guided automated trajectory collection framework. It combines tutorial-guided exploration with a hybrid GUI--Code action space, providing application-specific knowledge and simplifying GUI workflows through direct execution of application-native commands. The framework also checkpoints and revisits pivotal states during tree exploration to explore alternative workflows, complementing linear rollouts for broader coverage. We collect 10.9K automatically validated trajectories and use them to fine-tune open-source base models. The resulting model achieves 64.1\% accuracy on a benchmark of specialized desktop workflows, improving performance by 58.2 percentage points, establishing a new state of the art. The fine-tuned model also improves performance on general desktop workflows using GUI actions only, suggesting that the collected supervision benefits general desktop tasks as well. Comparative experiments and ablations demonstrate the efficiency of our collection framework and the value of code actions in specialized workflows.
