## 摘要
大语言模型（LLM）正推动自主智能体走向真实世界环境，而Web正成为最具代表性的交互场景之一。然而，采用朴素探索训练Web智能体仍然具有挑战性：成功轨迹稀少，且稀疏的终端奖励使智能体难以从失败轨迹中获得有用反馈。受技能习得理论启发，我们提出技能组合渐进探索（Skill-Composed Progressive Exploration, SCOPE），这是一种面向长程Web智能体的由短到长学习框架，将复杂任务探索分解为从局部技能到完整任务求解能力的逐步扩展过程。具体而言，SCOPE围绕局部技能进行迭代探索：技能发现（Skill Discovery）从历史rollout中提取可复用的局部技能与失败经验；技能编排（Skill Orchestration）将已发现的技能组合为高层技能链；技能扩展（Skill Expansion）利用与当前技能链对齐的失败经验，引导智能体探索新的子技能。通过这一过程，SCOPE在多次rollout中逐步构建完成任务所需的技能链，并通过智能体式同策略蒸馏将其内化到策略参数中。在WebArena、WebVoyager和WebShop上的大量实验表明，SCOPE持续改善探索动态，并在各设置下相较最强基线取得3.9%至18.6%的相对提升。

## Abstract
Large language models (LLMs) are driving autonomous agents toward real-world environments, with the Web emerging as one of the most representative interaction scenarios. However, training Web agents with naive exploration remains challenging: successful trajectories are rare, and the sparse terminal rewards make it difficult for agents to obtain useful feedback from failed trajectories. Inspired by skill acquisition theory, we propose Skill-Composed Progressive Exploration (SCOPE), a short-to-long learning framework for long-horizon Web agents that decomposes complex task exploration into a gradual expansion process from local skills to complete task-solving capability. Specifically, SCOPE iteratively explores around local skills: Skill Discovery extracts reusable local skills and failure experiences from historical rollouts; Skill Orchestration composes discovered skills into high-level skill chains; and Skill Expansion leverages failure experiences aligned with the current skill chain to guide the agent toward exploring new subskills. Through this process, SCOPE progressively constructs task-completing skill chains across rollouts and internalizes them into the policy parameters through agentic on-policy distillation. Extensive experiments on WebArena, WebVoyager, and WebShop show that SCOPE consistently improves exploration dynamics and achieves 3.9% to 18.6% relative gains over the strongest baselines in each setting.

## 1. 核心问题与研究动机

- **背景**：LLM 驱动的 Web 智能体需要在动态变化的真实网站上进行长程（long-horizon）交互决策，是连接自然语言指令与传统计算机系统操作流程的关键方向。现有训练范式（agentic RL）让智能体直接与环境交互、收集轨迹、用任务奖励优化策略。
- **核心痛点**（朴素端到端探索的两大失效）：
  - **成功稀疏（Sparse Successes）**：长程交互与动态网页状态使端到端随机探索极难命中成功轨迹；若任务深度为 L、单步正确概率为 p，则成功率随深度指数衰减（约 p^L）。
  - **失败未被利用（Unexploited Failures）**：奖励仅在终止步给出（0/1），失败轨迹往往被整体丢弃，即使其中某些片段包含有意义的局部进展，导致重复试错。
- **关键观察**：中间网页观测 o_t 记录了状态转移、界面变化、错误提示等信息，是稀疏奖励之外的额外反馈来源，可用来把长程任务拆成"可局部验证的子任务"。
- **理论启发**：借用 Fitts & Posner 的技能习得理论——复杂技能不是一次端到端习得，而是由简单技能逐步组合而成。
- **核心研究问题**：在成功轨迹难以通过朴素探索获得时，如何为长程任务提供有效且持续的探索支持？

## 2. 方法论：SCOPE（Skill-Composed Progressive Exploration）

### 2.1 核心思想
将 Web 任务探索分解为"从局部技能到完整任务求解"的由短到长渐进过程：在多次 rollout 之间不断**发现技能 → 编排技能链 → 借失败经验扩展前沿**，最终把拼装出的完整成功轨迹通过**智能体式同策略蒸馏**内化进策略参数。

### 2.2 四个关键组件

- **① 技能发现（Skill Discovery）**
  - 用辅助 LLM 执行 `DISCOVER(G, c, τ)`，依据任务目标 G、完成判据 c 与轨迹中的环境反馈，把轨迹切分为语义连贯的子任务单元：
    - ξ_i = (s_start^(i), A^(i), s_end^(i); m_i)，标签 y_i ∈ {0,1}
  - y_i=1 → 存入**技能记忆 B_skill**（被环境反馈验证可复用的子任务完成序列）；
  - y_i=0 → 存入**失败记忆 B_fail**（失败行为路径与失败原因）。
  - 两个记忆库互补：前者保存可复用进展，后者标记"在某条进展路径上被否证"的分支。

- **② 技能编排（Skill Orchestration）**
  - 把技能库视为以环境状态为节点、以技能为边的**状态图**；收集可达节点作为前沿候选集 S_frontier。
  - 用 LLM 执行 `SELECT(G, c, S_frontier)` 选出下一轮探索的前沿状态 s⋆。
  - **探索感知的前沿选择**：为每个前沿状态维护访问计数，提示 LLM 降低高频访问状态的权重，平衡"进展复用"与"探索多样性"（呼应 Go-Explore 思想）。
  - **鲁棒技能执行**：原始轨迹用 AXTree/HTML 的元素索引定位元素，跨页面会失效；因此抽取元素名称，在执行时重新 grounding 到当前页面上下文。

- **③ 技能扩展（Skill Expansion）**
  - 检索与 s⋆ 起点匹配的失败经验：F⋆ = {ξ_i ∈ B_fail | s_start^(i) = s⋆}。
  - 在**前沿的第一个动作**处施加干预，两种策略：
    - **OPTI（On-policy Teacher Intervention）**：由外部教师模型 `INTERVENE(G, s⋆, F⋆)` 直接生成动作并替换策略动作，引导更"强"。
    - **OPSI（On-policy Self Intervention）**：策略自身在失败摘要 `SUMMARIZE(G, p⋆, F⋆)` 条件下采样动作，a_self ∼ π_θ(·|G, s⋆, 摘要)，更贴近自身分布。
  - 干预后策略从新状态自主继续 rollout，因此在"智能体—环境交互步"层面仍保持 on-policy。

- **④ 技能蒸馏（Skill Distillation）**
  - 将渐进探索拼装出的、满足 R(τ̃)=1 的教师轨迹分布 q_SCOPE 蒸馏进策略：
    - L_distill(θ) = E_{G∼D, τ̃∼q_SCOPE}[ −Σ_t log π_θ(ã_t | G, s̃_t) ]
  - 教师轨迹混合两类动作：策略自身采样的非干预动作 + 前沿干预动作；蒸馏把"依赖失败经验条件分布 π_θ(a|G,s̃,F⋆)"压缩回"标准策略分布 π_θ(a|G,s̃)"，实现能力内化。

### 2.3 整体训练流程
- 外层训练轮次 r 与内层探索迭代 j=1..J 交替：
  - π_θ^(r) → 初始 rollout τ_0^(r) → (Discovery → Orchestration → Expansion) 迭代 J 次得到 τ_j^(r) → Skill Distillation → π_θ^(r+1)
- 完整流程见附录 Algorithm 1。

### 2.4 理论分析（Proposition 1）
- 在"局部正确的前沿扩展决策概率下界为 p"且"固定深度下相关网页功能模式数量有界"的假设下，前沿候选状态数随深度呈多项式增长（≤ Ck^α，α 为任务关键约束维度），由此：
  - **Std(T_total) = O( L^{(1+2α)/2} / p )**，即渐进探索所需 rollout 数的波动为**多项式级**；
  - 对比朴素从头探索需连续做对 L 个关键决策，成功率为 p^L，等待时间与波动均为**指数级**。
