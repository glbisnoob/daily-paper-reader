# A Multi-Modal Robotic Framework for Physical GUI Interaction Testing 

## Davi Freitas 

Federal University of Pernambuco (UFPE) Brazil dsf3@cin.ufpe.br 

Abstract 

Automated testing of mobile applications remains challenging when realistic user interactions must be reproduced and GUI behavior verified without relying on invasive mechanisms such as instru-mentation or ADB-level control. Existing approaches, including DLD and R-DLD, detect data loss triggered by activity restarts but still depend on system-level access, which limits their applicability on real devices. This doctoral research proposes RFNIT, a multi-modal, fully non-invasive robotic framework for physical GUI interaction testing on smartphones. RFNIT supports end-to-end automation by per-ceiving the device state through external sensing and executing physical interactions, enabling human-like actions while preserving reproducibility and execution accuracy. The framework integrates a vision-based perception module, an LLM-driven reasoning agent, and a robotic actuator capable of per-forming touch, swipe, and typing gestures. Multimodal data, includ-ing external camera images and OCR-extracted text, are combined to identify GUI elements and guide subsequent testing decisions. Preliminary results indicate that RFNIT accurately recognizes buttons, text fields, and virtual keyboards from external camera input, achieving over 85% visual detection accuracy. Ongoing and future work will focus on improving robustness, repeatability, and coverage of GUI states during long-running testing sessions. 

Keywords 

Non-invasive testing, robotics testing, computer vision, mobile applications, GUI testing

2 Research Problem and Objectives 

Despite the progress in GUI testing automation, a major gap persists between invasive software-level testing and non-invasive physical testing. Invasive methods such as ADB- or instrumentation-based testing can achieve fine-grained control of app states but fail to operate in realistic user conditions. Conversely, robotic systems that execute touch events on real devices are constrained by limited perception and reasoning capabilities. Bridging this gap requires a unified framework that enables robots to interpret and act upon the visual state of the device, autonomously and intelligently. The overarching research problem of this thesis can be summa-rized as follows: 

How can we design a robotic testing framework that performs reliable, autonomous, and human-like GUI interactions on real smartphones without requiring in-vasive system access? 

To address this problem, the research is guided by the following objectives: 

O1 – Develop a non-invasive architecture for automated GUI testing: design a framework that integrates vision-based percep-tion, LLM-driven reasoning, and robotic actuation to perform end-to-end interactions on real devices. 

O2 – Enable multimodal understanding of interface states: 

combine external camera images, and OCR-extracted text to accu-rately identify interactive components and infer app states. 

O3 – Achieve adaptive testing strategies: implement a decision-making mechanism that allows the framework to select the next interaction step based on its perception and testing goals. 

O4 – Evaluate the approach in realistic environments: validate RFNIT’s performance through experiments involving real Android applications, measuring coverage, repeatability, and robustness during long testing sessions. By pursuing these objectives, RFNIT aims to extend the current boundaries of mobile testing automation, bringing together the pre-cision of robotic actuation and the flexibility of AI-driven reasoning. The resulting framework seeks to advance the understanding of how perception, cognition, and physical interaction can coexist in software testing tools for mobile platforms. 

3 Proposed Approach: The RFNIT Framework 

The proposed RFNIT integrates three complementary modali-ties—vision, reasoning, and control—into a unified non-invasive testing architecture (Figure 2). 

3.1 Vision and Perception 

An external camera (Logitech BRIO 4K) captures real-time images of the smartphone screen. The visual processing pipeline combines OpenCV-based preprocessing for perspective correction and bright-ness normalization, layout extraction from Android XML dumps, object detection using YOLOv8 trained on GUI datasets, and text recognition via PaddleOCR. The result is a multimodal representa-tion of the interface that integrates visual and semantic information about buttons, text fields, and interactive regions. 

3.2 Reasoning and Decision-Making 

An LLM acts as a decision-making agent that interprets the visual state of the interface and the testing task to select the next interac-tion. The agent performs goal-driven exploration guided by natural language instructions, reasons about application state transitions and missing elements to identify potential data loss or UI faults, and continuously adapts its strategy based on feedback from prior executions. 

3.3 Physical Interaction 

The robot executes the selected action physically on the smartphone through a controlled actuation mechanism. Each touch, swipe, or typing command is translated into precise servo or actuator control signals. Visual feedback is continuously used to verify whether the intended action produced the expected interface state transi-tion, enabling a closed-loop perception–action feedback cycle that improves robustness and execution accuracy. 

4 Preliminary Results 

A functional RFNIT prototype was implemented using Python, OpenCV, and the Ultralytics YOLOv8 framework. Experiments were conducted on five Android applications (e.g., messaging, weather, and shopping apps), using an external Logitech BRIO 4K camera operating under natural ambient lighting conditions. The system successfully identified interactive components and executed physi-cal tap actions through a robotic actuator with an average precision of 2.0 mm. These results demonstrate the feasibility of end-to-end multimodal perception and physical interaction without instrumentation. 

5 Evaluation Plan 

The next phase of this research will conduct a comprehensive eval-uation of RFNIT along the following dimensions: 

Coverage and efficiency: Quantitatively compare state coverage, execution time, and the number of unique interaction transitions against established baselines, including DLD and DroidBot. 

Realism and usability: Perform controlled user studies to assess the degree to which robotic actions align with human interaction patterns, focusing on perceived naturalness, gesture fidelity, and operational intuitiveness. 

Reproducibility and robustness: Execute repeated test sessions under varying environmental and device conditions. Metrics such as visual detection precision, action latency, and physical alignment accuracy will be systematically measured to characterize stability and performance. Overall, this evaluation aims to rigorously demonstrate the via-bility of RFNIT as a general-purpose, multimodal, and fully non-invasive robotic testing framework for real mobile devices. 

6 Challenges and Future Work 

Despite promising initial results, several challenges remain: 

Latency and synchronization: Aligning perception, reasoning, and actuation in real time remains complex, especially as gesture complexity increases. 

Visual occlusion and reflection: External cameras are sensitive to glare and variability in ambient light, which can interfere with computer vision pipelines. 

Reasoning reliability: LLMs may produce inconsistent decisions when faced with ambiguous or partially occluded interfaces. 

Scalability: Extending testing to multiple devices and concurrent executions requires sophisticated coordination strategies. To extend the platform’s physical capabilities, we are developing a new robotic gripper that supports rapid smartphone replacement and magnetic USB coupling for automatic power connection. In par-allel, we are designing a dynamic grip reconfiguration mechanism that allows the robot to change the device’s orientation or handed-ness during testing, enabling inversion, rotation, and repositioning to support complex gestures and access to side buttons. 

7 Expected Contributions 

This research is expected to make the following contributions: 

A fully non-invasive robotic testing framework for multi-modal GUI interaction on physical mobile devices, enabling ex-ternal vision–based perception, reasoning-driven action selection, and precise robotic execution without requiring instrumentation or system-level access. 

A publicly available, large-scale dataset composed of synchro-nized camera captures, supporting research on visual understand-ing, GUI element detection, and multimodal test generation. 

Empirical evidence and methodological insights on how large reasoning models can be integrated with physical testing work-flows, including analysis of decision reliability, perception–action coupling, and failure modes in real-world scenarios. 

A conceptual and practical foundation for hybrid AI–robotic testing methodologies , bridging software testing, mobile automa-tion, computer vision, and robotic manipulation to support future research on autonomous, embodied testing agents.
