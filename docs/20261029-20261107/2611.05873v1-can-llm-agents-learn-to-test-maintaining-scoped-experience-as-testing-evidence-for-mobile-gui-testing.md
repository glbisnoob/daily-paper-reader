## 摘要
重复的移动 GUI 测试可以复用先前执行中的路径、定位器和恢复策略。然而，在某个工作流或应用版本中有效的路径，在另一个工作流或版本中可能无关紧要甚至具有误导性。我们研究基于 LLM 的测试器如何保留有用经验，同时抑制与当前观察相矛盾的条目。我们提出 AdaptiTest 的维护契约，其中可复用经验具有显式的适用作用域、轨迹来源，以及用于确认、重新验证和撤回的生命周期。该契约将持久化保留给 Reflector 角色，并将召回的经验视为建议。归档实现并未建立对每个指定机制的端到端强制执行。该设计改变的是检索到的上下文，而非模型权重。评估使用只读 Android 工作流和归档的内部比较。一个包含六个任务、三次重复的可用子集报告：有记忆时 18/18 次运行完成，而无记忆时为 3/18，但一个有环境依据的单智能体对照也解决了较早的困难任务切片。一个单独的跨会话探测因路径调度混杂和状态标签未经验证而被排除在有效性结论之外。我们检查了九个受试者中的 13 条选定的真实更新风险记录，区分过期定位器观察、基于策略的抑制和离线检索诊断。后者并不衡量实时设备故障或节省的动作。这些事件是 UI 变化，而非已确认的回归缺陷。证据支持一个有界的设计与案例研究；它并未确立普遍有效性、优于独立 GUI 智能体系统，或无限制探索。

## Abstract
Repeated mobile GUI tests can reuse routes, locators, and recovery strategies from earlier executions. However, a route that worked in one workflow or app version may be irrelevant or misleading in another. We study how an LLM-based tester can retain useful experience while withholding entries contradicted by current observations. We present a maintenance contract for AdaptiTest in which reusable experience has an explicit applicability scope, trace provenance, and a lifecycle for confirmation, revalidation, and withdrawal. The contract reserves persistence for a Reflector role and treats recalled experience as advice. The archived implementation does not establish end-to-end enforcement of every specified mechanism. The design changes retrieved context, not model weights. The evaluation uses read-only Android workflows and archived internal comparisons. A six-task, three-repeat ready subset reports 18/18 completed runs with memory versus 3/18 without it, but a grounded single-agent control also solves the earlier hard-task slice. A separate cross-session probe is excluded from efficacy conclusions because of confounded route schedules and unvalidated state labels. We examine 13 selected real-update hazard records across nine subjects, distinguishing stale-locator observations from policy-based withholding and offline retrieval diagnostics. The latter do not measure live-device failures or actions saved. These events are UI changes, not confirmed regression bugs. The evidence supports a bounded design and case study; it does not establish general efficacy, superiority over independent GUI-agent systems, or unrestricted exploration.
