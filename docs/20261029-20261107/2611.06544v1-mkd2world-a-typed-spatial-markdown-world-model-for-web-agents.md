## 摘要
图形用户界面（GUI）智能体能够借助世界模型的前瞻能力改进决策，前提是预测状态能够准确反映动作后的界面。现有状态表示无法同时捕捉界面布局、UI 语义和显式位置。我们提出类型化空间 Markdown（Typed Spatial Markdown, TSM），一种面向桌面 Web 界面的 Markdown 风格文本状态表示。TSM 按照空间关系序列化块级和原子级 UI 元素，联合编码其类型、视觉语义、显式位置、可选控件状态以及层级归属关系。为了训练截图到 TSM 的渲染器，我们构建了 AtomBlock-WebUI，一个在两种粒度上均具有精确标注的数据集。通过将元素类型标签注入 HTML，并在渲染后直接提取边界框，我们避免了因从网页结构进行事后推断而导致的标注错误。基于 TSM，我们提出 MKD2World，一个桌面 Web 世界模型，分两阶段训练，用于当前状态描述和动作条件下的下一状态预测。在推理过程中，Web 智能体按需查询 MKD2World，并执行“摘要”（digest）步骤，在其中解释每个预测状态并提取任务相关证据，以选择最佳动作。实验表明，MKD2World-9B 在域外测试集上取得 26.50 的 EleF1 分数，比 GPT-5.6-Sol（14.98）高出 11.52 分。在 Online-Mind2Web 任务上，MKD2World-9B 将 Qwen3.5-35B Web 智能体的成功率从 22.94% 提升至 37.61%，在领先的开源 GUI 世界模型中达到有竞争力的性能。代码见 https://github.com/OmniAI-Lab-CUHKSZ/MKD2World。

## Abstract
Graphical user interface (GUI) agents can improve decision-making with world-model foresight, provided that predicted states accurately reflect post-action interfaces. Existing state representations fail to jointly capture interface layout, UI semantics, and explicit locations. We introduce Typed Spatial Markdown (TSM), a Markdown-style textual state representation for desktop web interfaces. TSM serializes block-level and atomic-level UI elements according to their spatial relationships, jointly encoding their types, visual semantics, explicit locations, optional control states, and hierarchical membership. To train a screenshot-to-TSM renderer, we construct AtomBlock-WebUI, a dataset with precise annotations at both granularities. By injecting element-type labels into HTML and directly extracting bounding boxes after rendering, we avoid annotation errors caused by post-hoc inference from webpage structures. Building on TSM, we propose MKD2World, a desktop web world model trained in two stages for current-state description and action-conditioned next-state prediction. During inference, the web agent queries MKD2World as needed and performs a ``digest'' step, in which it interprets each predicted state and extracts task-relevant evidence for selecting the best action. Experiments show that MKD2World-9B achieves an EleF1 score of 26.50 on the out-of-domain test set, outperforming GPT-5.6-Sol(14.98) by 11.52 points. ### 2.3 MKD2World 两阶段训练

- **基座与微调**：Qwen3.5-9B + LoRA（rank 32、α=64、dropout 0.05，覆盖全部 32 个语言层及 27 个视觉编码器块的 attention/MLP）。
- **阶段一（当前状态重建）**：\(I_t \rightarrow M_t\)，token 级因果交叉熵。
- **阶段二（动作条件下一状态预测）**：\((I_t,a_t)\rightarrow M_{t+1}\)，元素级交叉熵
  \[
  \mathrm{CE}_{\text{Ele}}(e)=-\frac{1}{|e|}\sum_{j\in e}\log p_\theta(y_j\mid I_t,a_t,y_{<j})
  \]
- **Base–Focus 元素损失**：对 add/update 的“焦点元素”加权，
  \[
  \mathcal{L}_{\text{BF-Ele}}^{(i)}=\frac{\sum_{e\in N_i}\mathrm{CE}(e)+\lambda_i\sum_{e\in F_i}\mathrm{CE}(e)}{|N_i|+\lambda_i|F_i|},\quad \lambda_i=\min\!\left(3,\sqrt{|N_i|/|F_i|}\right)
  \]
  焦点稀疏时用 \(\sqrt{\cdot}\) 修正、上限 3 防止小集合主导；无焦点元素时退化为全页平均损失。
- **边际排序损失**：仅在“changed”转移上启用，
  \[
  \mathcal{L}_{\text{margin}}^{(i)}=\mathbb{I}[i\in C]\left[m+\mathrm{CE}_{\text{page}}(M_{t+1}^{(i)})-\mathrm{CE}_{\text{page}}(M_t^{(i)})\right]_+
  \]
  强制模型在相同 \((I_t,a_t)\) 下更偏好真实下一状态而非当前状态的反事实，以区分“动作引起变化”与“复述当前界面”。
- **总目标**：\(\mathcal{L}_{\text{final}}=\frac{1}{B}\sum_i(\mathcal{L}_{\text{BF-Ele}}^{(i)}+\beta(s)\mathcal{L}_{\text{margin}}^{(i)})\)，\(\beta(s)\) 随训练步逐渐增大。
- **转移数据**：从 WebChain 与 MolmoWeb-HumanTrajs 提取 \((I_t,a_t,I_{t+1})\)，经渲染得到 TSM，并划分为 exact noop / near noop / changed（哈希、SSIM≥0.98、RGB-MAE≤0.002、Edge-F1≥0.98 等阈值）。
